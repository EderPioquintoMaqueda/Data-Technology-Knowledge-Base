# ⚠️ False Cognates (False Friends) | Falsos amigos

## Tech false friends 💻
| English | Means | Not |
|---|---|---|
| **actual** value | valor **real** | valor actual (= current value) |
| **application** | app / solicitud de empleo | aplicación (de un producto: use) |
| **directory** | carpeta / directorio | directorio telefónico (también) |
| **compile** | compilar | — |
| **resume** (v.) /rɪˈzuːm/ | reanudar | resumir (= summarize) |
| **résumé / resume** (n.) /ˈrez.ə.meɪ/ | currículum | resumen (= summary) |
| **execute** | ejecutar (un programa) | — (also "ejecutar" a alguien!) |
| **data** | datos (plural/uncountable) | dato (= data point) |

## 🧪 Practice — choose the right word
1. I'll ___ the meeting tomorrow. (assist / attend)
2. ___, the model is not as accurate as we thought. (Actually / Currently)
3. I didn't ___ the error until today. (realize / carry out)
4. Can you send me your ___? (résumé / summary) — for a job.
<details><summary>Answers</summary>1 attend · 2 Actually · 3 realize · 4 résumé</details>
