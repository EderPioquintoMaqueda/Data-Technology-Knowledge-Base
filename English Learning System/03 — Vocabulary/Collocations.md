# 🔗 Collocations | Combinaciones naturales de palabras

A **collocation** is a pair of words that natives always use together. *Make a decision* ✅ · *do a decision* ❌. Learn words **in pairs**, not alone.

## 1. MAKE vs DO
| MAKE (create, produce, decide) | DO (tasks, work, activities) |
|---|---|
| make a decision — tomar una decisión | do your job — hacer tu trabajo |
| make a mistake — cometer un error | do research — investigar |
| make progress — avanzar | do an analysis — hacer un análisis |
| make a change — hacer un cambio | do a favour — hacer un favor |
| make a plan — hacer un plan | do business — hacer negocios |
| make money — ganar dinero | do your best — hacer lo mejor posible |
| make an effort — esforzarse | do the dishes — lavar los trastes |
| make a call — hacer una llamada | do a course — tomar un curso |
| make sure — asegurarse | do damage — causar daño |
| make sense — tener sentido | do a test — hacer una prueba |
| make a suggestion — sugerir | do overtime — hacer horas extra |
| make an appointment — hacer una cita | do the paperwork — hacer el papeleo |

## 2. TAKE / HAVE / GET
| TAKE | HAVE | GET |
|---|---|---|
| take a break — tomar un descanso | have a meeting — tener una reunión | get feedback — recibir retroalimentación |
| take notes — tomar notas | have a look — echar un vistazo | get access — obtener acceso |
| take a risk — arriesgarse | have a question — tener una pregunta | get started — empezar |
| take time — tomar tiempo | have an idea — tener una idea | get results — obtener resultados |
| take responsibility — asumir responsabilidad | have a problem with | get an error — obtener un error |
| take place — tener lugar | have lunch — comer | get promoted — ser ascendido |
| take into account — tomar en cuenta | have experience in | get in touch — ponerse en contacto |
| take action — actuar | have a chance — tener oportunidad | get rid of — deshacerse de |

## 5. Adjective + preposition (very common errors)
| ✅ | ❌ |
|---|---|
| interested **in** | interested ~~on~~ |
| good **at** | good ~~in~~ (for skills) |
| responsible **for** | responsible ~~of~~ |
| depend **on** | depend ~~of~~ |
| familiar **with** | familiar ~~to~~ (for skills) |
| similar **to** | similar ~~than~~ |
| different **from** | different ~~than~~ (US ok) / ~~of~~ |
| married **to** | married ~~with~~ |
| aware **of** | aware ~~about~~ |
| consist **of** | consist ~~in~~ |
| arrive **at/in** | arrive ~~to~~ |
| listen **to** | listen ~~(nothing)~~ |
