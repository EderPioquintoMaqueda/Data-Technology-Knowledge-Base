# 💬 Idioms and Expressions | Modismos y expresiones

Idioms have meanings you can't guess from the words. Learn the ones used **at work** first.

## 1. Workplace idioms
| Idiom | Meaning | Español | Example |
|---|---|---|---|
| on the same page | agree / understand the same | estar en la misma sintonía | Let's make sure we're **on the same page** about the scope. |
| touch base | contact briefly | ponerse en contacto | I'll **touch base** with the client tomorrow. |
| circle back | return to a topic later | retomar después | Let's **circle back** to this after lunch. |
| ballpark figure | rough estimate | cifra aproximada | Can you give me a **ballpark figure**? |
| low-hanging fruit | easy wins | lo más fácil de lograr | Fixing the indexes is **low-hanging fruit**. |
| think outside the box | be creative | pensar fuera de la caja | We need to **think outside the box**. |
| get the ball rolling | start | poner en marcha | Let's **get the ball rolling** on the migration. |
| back to square one | start again | volver a empezar | The test failed — **back to square one**. |
| cut corners | do poorly to save time | hacer algo a medias | Don't **cut corners** on testing. |
| the bottom line | the essential point / profit | lo esencial | **The bottom line** is we need more data. |
| up to speed | informed | al día | Can you bring me **up to speed**? |
| a heads-up | advance warning | aviso previo | Just **a heads-up**: the server will restart at 6. |
| on track | progressing as planned | en buen camino | The project is **on track**. |
| behind schedule | late | atrasado | We're two weeks **behind schedule**. |
| in the loop | informed | al tanto | Please keep me **in the loop**. |
| hit the ground running | start fast and well | empezar con todo | The new analyst **hit the ground running**. |
| a steep learning curve | hard to learn at first | curva de aprendizaje empinada | Spark has **a steep learning curve**. |
| bite off more than you can chew | take on too much | abarcar demasiado | Don't **bite off more than you can chew**. |
| drop the ball | make a mistake / forget | fallar / descuidar algo | Sorry, I **dropped the ball** on that email. |
| call it a day | stop working | dar por terminado el día | It's 7 p.m. — let's **call it a day**. |
| under the weather | slightly sick | indispuesto | I'm a bit **under the weather** today. |
| a win-win | good for both sides | ganar-ganar | It's **a win-win** for both teams. |
| pull your weight | do your fair share | poner de tu parte | Everyone needs to **pull their weight**. |
| the elephant in the room | obvious problem nobody mentions | el tema incómodo | Data quality is **the elephant in the room**. |
| move the needle | make a noticeable difference | hacer una diferencia notable | This feature won't **move the needle**. |

## 2. Tech slang
| Expression | Meaning |
|---|---|
| it works on my machine | excuse: fails elsewhere — *funciona en mi computadora* |
| garbage in, garbage out (GIGO) | bad input → bad output |
| rabbit hole | endless investigation — *perderse investigando* |
| bikeshedding | arguing about trivial details |
| yak shaving | many small tasks before the real one |
| ship it | release it |
| dogfooding | using your own product |
| tech debt | shortcuts that cost later — *deuda técnica* |
| a quick win | easy improvement |
| sanity check | quick verification — *verificación rápida* |
| edge case | unusual situation — *caso límite* |
| happy path | normal flow without errors |
| out of the box | works without configuration |
| under the hood | internally |
| boilerplate | repetitive template code |
