# 🗣️ How to Read Pronunciation | Cómo leer la pronunciación

Every vocabulary table in this vault has two pronunciation columns:

| Column | What it is | Example: *database* |
|---|---|---|
| **IPA** | International Phonetic Alphabet — exact, used by dictionaries | /ˈdeɪ.t̬ə.beɪs/ |
| **Sounds like (ES)** | Spanish-style respelling to help you start | **DÉI**-ta-beis |

## 1. Rules of the "Sounds like" column
1. **CAPITAL / bold syllable = stressed** (more force, longer). *de-VE-lop* → develop.
2. Read the respelling **with Spanish letters**, except these special symbols:

| Respelling | English sound | IPA | How to make it | Example |
|---|---|---|---|---|
| **z** | "th" sorda | /θ/ | tongue between the teeth, blow air (like "z" in Spain) | think → **zink** |
| **d** (in *th* words) | "th" sonora | /ð/ | same position, with voice | this → **dis**, they → **dei** |
| **sh** | /ʃ/ | /ʃ/ | "shhh" (silencio) | she → **shi** |
| **ch** | /tʃ/ | /tʃ/ | like Spanish "ch" | check → **chek** |
| **y** (before vowel, in *j/g* words) | /dʒ/ | /dʒ/ | like a strong Argentine "y" / "ll" | job → **yab**, generate → **YE**-ne-reit |
| **j** | /h/ | /h/ | soft breath, NOT the Spanish "j" | hello → **je-LOU** |
| **v** | /v/ | /v/ | upper teeth on lower lip (different from b!) | value → **VAL-yu** |
| **z** (between vowels / end in plurals) | /z/ | /z/ | buzzing "s" like a bee | is → **iz** |
| **u** + vowel | /w/ | /w/ | rounded lips | week → **uik** |
| **ng** | /ŋ/ | /ŋ/ | back of tongue, no "g" at the end | string → **string** |
| **er** (unstressed) | /ɚ/ | /ɚ/ | weak "r" vowel, tongue curled | computer → kom-**PIU**-ter |

3. Vowels: the respelling uses the **closest** Spanish vowel. English has ~12 vowel sounds vs 5 in Spanish, so always check the IPA and listen.

## 2. IPA vowels you must know
| IPA | Description | Examples |
|---|---|---|
| /iː/ | long "i" | see, key, team, query /ˈkwɪr.i/ ends in /i/ |
| /ɪ/ | short, relaxed "i" (between i and e) | sit, list, big |
| /e/ | like Spanish "e" | set, bed, test |
| /æ/ | open "a" (mouth wide, between a and e) | cat, back, stack, map |
| /ʌ/ | short "a" (relaxed) | cup, run, bug, sum |
| /ɑː/ | open long "a" | car, start, lot (US) |
| /ɔː/ | open "o" | law, sort, call |
| /ʊ/ | short "u" | book, put, pull |
| /uː/ | long "u" | food, tool, true |
| /ə/ | **schwa** — the most common sound, weak and neutral | **a**bout, comput**er**, sof**a** |
| /ɝː/ | "er" stressed | work, first, server |

### Diphthongs (two vowels glued)
| IPA | Sounds like | Examples |
|---|---|---|
| /eɪ/ | "ei" | day, table, data |
| /aɪ/ | "ai" | my, file, type |
| /ɔɪ/ | "oi" | join, point |
| /aʊ/ | "au" | now, out, cloud |
| /oʊ/ | "ou" | go, code, load |

## 3. Five tips for Spanish speakers
1. **Don't add "e" before s + consonant:** *Spain* ≠ "Espain", *school* ≠ "eschool", *SQL* = "es-kiu-el".
2. **Final consonants are pronounced:** *test* (not "tes"), *asked* /æskt/.
3. **b ≠ v:** *very* vs *berry*.
4. **Stress changes meaning:** *REcord* (noun) vs *reCORD* (verb), *PREsent* vs *preSENT*.
5. **Schwa everywhere:** unstressed vowels become /ə/ — *banana* = /bəˈnæn.ə/.
