# 🔄 Passive Voice | Voz pasiva

Use the passive when the **action or result** matters more than **who** did it — extremely common in technical documentation and reports.
- Active: *The analyst **cleaned** the data.*
- Passive: *The data **was cleaned** (by the analyst).*

## 1. Formula
**Object + BE (in the right tense) + Past Participle (+ by agent)**

| Tense | Active | Passive |
|---|---|---|
| Present simple | They **store** the logs in S3. | The logs **are stored** in S3. |
| Present continuous | They **are migrating** the DB. | The DB **is being migrated**. |
| Past simple | Ana **wrote** the script. | The script **was written** by Ana. |
| Past continuous | They **were updating** the table. | The table **was being updated**. |
| Present perfect | We **have fixed** the bug. | The bug **has been fixed**. |
| Past perfect | They **had deleted** the file. | The file **had been deleted**. |
| Future (will) | We **will deploy** the model. | The model **will be deployed**. |
| Be going to | They **are going to replace** it. | It **is going to be replaced**. |
| Modal | You **must encrypt** passwords. | Passwords **must be encrypted**. |
| Modal perfect | Someone **should have tested** it. | It **should have been tested**. |
| Infinitive | I need someone **to review** this. | This needs **to be reviewed**. |
| Gerund | I don't like people **interrupting** me. | I don't like **being interrupted**. |

## 2. When to use it
- Agent unknown or obvious: *My laptop **was stolen**.* · *The results **were published** yesterday.*
- Technical / scientific writing: *The data **was split** into training and test sets.*
- Processes: *First, the file **is uploaded**; then it **is validated** and **loaded** into the warehouse.*
- To sound diplomatic: *Mistakes **were made**.* (instead of *You made mistakes*)

## 3. Spanish "SE" → English passive
| Español | English |
|---|---|
| **Se** habla inglés. | English **is spoken**. |
| **Se** encontró un error. | An error **was found**. |
| **Se** recomienda usar índices. | Using indexes **is recommended**. / It **is recommended** to use indexes. |
| **Se** dice que… | It **is said** that… / X **is said to**… |

## 4. Advanced passive structures
| Structure | Example |
|---|---|
| Impersonal passive | **It is expected that** the migration will finish today. |
| Personal passive | The migration **is expected to finish** today. |
| Causative *have/get something done* | We **had the servers upgraded**. / I **got my laptop fixed**. |
| Passive with two objects | They gave **me** access → **I was given** access. |
| *By* vs *with* | written **by** Ana (agent) · opened **with** a key (instrument) |

## 5. Technical writing examples
- *The model **was trained** on 2 million records and **evaluated** using 5-fold cross-validation.*
- *All passwords **are hashed** before they **are stored**.*
- *The pipeline **is triggered** whenever a new file **is uploaded**.*
- *This endpoint **has been deprecated** and **will be removed** in v3.*

## 🧪 Practice — change to passive
1. Someone deleted the production table. 2. They will release version 2.0 next month. 3. The team is reviewing the code. 4. You should back up the database daily.
<details><summary>Answers</summary>

1. The production table was deleted. 2. Version 2.0 will be released next month. 3. The code is being reviewed. 4. The database should be backed up daily.
</details>
