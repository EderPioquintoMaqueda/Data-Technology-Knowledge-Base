# 📍 Prepositions | Preposiciones

## 1. Time: AT – ON – IN (triangle: specific → general)
| AT (exact time) | ON (days & dates) | IN (longer periods) |
|---|---|---|
| at 9 a.m. | on Monday | in November |
| at noon / at midnight | on November 18th | in 2026 |
| at the weekend (UK) | on the weekend (US) | in the morning / afternoon / evening |
| at night | on my birthday | in the summer |
| at the moment | on Friday morning | in two weeks (future: dentro de) |
| at the end of the month | on time (puntual) | in time (a tiempo, antes del límite) |

⚠️ No preposition with **this, next, last, every**: *I'll do it **next** week* (not *in next week*).

## 2. Place: AT – ON – IN
| AT (a point) | ON (a surface / line) | IN (inside / enclosed) |
|---|---|---|
| at the office | on the desk | in the room |
| at the bus stop | on the wall | in the folder |
| at home / at work | on the second floor | in Mexico City |
| at the meeting | on the screen | in the database |
| at IBM (company) | on the website / on page 5 | in the email / in the report |
| at the corner | on the left / right | in the queue |

Tech: **in** a file / table / column / folder / repo · **on** a server / platform / GitHub / the cloud / a branch · **at** line 42 / an address.

## 3. Movement and direction
| Preposition | Example | Español |
|---|---|---|
| to | Go **to** the office. Send it **to** me. | a, hacia |
| into | Load the data **into** the table. | dentro de (movimiento) |
| out of | Get **out of** the loop. | fuera de |
| from … to | **from** 9 **to** 5 · **from** CSV **to** Parquet | de … a |
| through | The request goes **through** a proxy. | a través de |
| across | **across** all regions | a lo largo de / en todo |
| over / under | **over** 1,000 rows · **under** 5 seconds | más de / menos de |
| towards | **towards** the goal | hacia |
| onto | Drag the file **onto** the window. | sobre (movimiento) |

## 4. Other key prepositions
| Preposition | Uses | Example |
|---|---|---|
| for | duration, purpose, beneficiary | **for** 3 hours · a tool **for** analysis · **for** you |
| since | starting point | **since** 2024 · **since** Monday |
| during | within a period | **during** the meeting |
| by | deadline, agent, method | **by** Friday · written **by** Ana · **by** email |
| until / till | up to a time | wait **until** 5 |
| with / without | accompaniment / absence | **with** filters · **without** errors |
| about | topic | a talk **about** SQL |
| per | rate | 100 requests **per** second |
| via | by means of | **via** API |
| against | opposition / comparison | test **against** production data |
| among / between | many / two | **between** A and B · **among** the team |
| according to | según | **according to** the logs |
| due to | debido a | delayed **due to** the outage |
| instead of | en lugar de | Polars **instead of** pandas |

## 5. ⚠️ Common mistakes of Spanish speakers
| ❌ | ✅ |
|---|---|
| depend **of** | depend **on** |
| married **with** | married **to** |
| arrive **to** the office | arrive **at** the office / **in** a city |
| think **in** you | think **of / about** you |
| consist **in** | consist **of** |
| good **in** math | good **at** math |
| explain **me** | explain **to me** |
| I'm agree | I agree (no preposition, no "am") |
| enter **to** the system | enter the system / log **in to** the system |
| discuss **about** | discuss (no preposition) |
| in the next week | next week |
