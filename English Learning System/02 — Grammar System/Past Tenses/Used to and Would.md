# Used to and Would

## 1. Introducción

En inglés existen diferentes maneras de hablar sobre hábitos, rutinas y situaciones que existían en el pasado.

Dos estructuras especialmente importantes son:

- **Used to:** describe hábitos, rutinas y estados que eran habituales o verdaderos en el pasado, pero que generalmente ya no lo son.
    
- **Would:** describe acciones repetidas o hábitos del pasado, especialmente cuando estamos contando recuerdos o narrando experiencias.
    

Observa:

- I used to work in a factory.  
    Antes trabajaba en una fábrica.
    
- When I was younger, I would visit my grandparents every weekend.  
    Cuando era más joven, solía visitar a mis abuelos todos los fines de semana.
    

Ambas estructuras permiten hablar de situaciones anteriores, pero no funcionan exactamente igual.

## 2. Used to

### 2.1 ¿Qué significa?

La estructura **used to** expresa algo que ocurría habitualmente en el pasado o una situación que era verdadera anteriormente.

Normalmente implica un contraste con el presente.

Examples:

- I used to play football.  
    Antes jugaba fútbol.
    
- She used to live in Mexico City.  
    Antes vivía en Ciudad de México.
    
- We used to work together.  
    Antes trabajábamos juntos.
    
- He used to be very shy.  
    Antes era muy tímido.
    

En estos ejemplos, la estructura presenta hábitos o situaciones anteriores que ya no necesariamente continúan.

### 2.2 Estructura afirmativa

**Structure:**

`Subject + used to + base form of the verb + complement`

|Subject|Structure|Example|
|---|---|---|
|I|used to|I used to study English.|
|You|used to|You used to work here.|
|He|used to|He used to play football.|
|She|used to|She used to drive to work.|
|It|used to|It used to work properly.|
|We|used to|We used to live nearby.|
|They|used to|They used to visit us.|

La estructura es igual para todos los sujetos.

**Importante:** después de _used to_ utilizamos el verbo en su forma base.

Correcto:

- I used to work.
    
- She used to study.
    
- They used to drive.
    

Incorrecto:

- I used to worked.
    
- She used to studied.
    
- They used to drove.
    

### 2.3 Estructura negativa

Para construir la forma negativa utilizamos:

`Subject + did not + use to + base form`

La estructura cambia de _used to_ a _use to_ porque el auxiliar _did_ ya indica el pasado.

Examples:

- I didn't use to like coffee.  
    Antes no me gustaba el café.
    
- She didn't use to work remotely.  
    Antes no trabajaba de manera remota.
    
- We didn't use to have internet access.  
    Antes no teníamos acceso a internet.
    
- They didn't use to communicate online.  
    Antes no se comunicaban por internet.
    

**Forma contraída:**

`did not = didn't`

### 2.4 Estructura interrogativa

Utilizamos:

`Did + subject + use to + base form?`

Examples:

- Did you use to play football?  
    ¿Antes jugabas fútbol?
    
- Did she use to work here?  
    ¿Antes trabajaba aquí?
    
- Did they use to live in this city?  
    ¿Antes vivían en esta ciudad?
    

Respuestas cortas:

- Yes, I did.
    
- No, I didn't.
    
- Yes, she did.
    
- No, she didn't.
    

**Importante:** después de _did_ utilizamos _use to_, no _used to_.

Incorrecto:

- Did you used to work here?
    

Correcto:

- Did you use to work here?
    

## 3. Usos principales de Used to

### 3.1 Hábitos anteriores

Describe acciones que se repetían en el pasado.

Examples:

- I used to run every morning.  
    Antes corría todas las mañanas.
    
- My father used to read the newspaper every day.  
    Mi padre solía leer el periódico todos los días.
    
- We used to travel during the holidays.  
    Antes viajábamos durante las vacaciones.
    

### 3.2 Situaciones o estados anteriores

Una de las ventajas más importantes de _used to_ es que permite hablar de estados, no solamente de actividades repetidas.

Examples:

- I used to be very interested in electronics.  
    Antes me interesaba mucho la electrónica.
    
- She used to know the manager.  
    Antes conocía al gerente.
    
- This machine used to be more efficient.  
    Esta máquina antes era más eficiente.
    
- There used to be a small office here.  
    Antes había una oficina pequeña aquí.
    

### 3.3 Comparar el pasado con el presente

Podemos utilizar _used to_ para explicar cómo han cambiado nuestras circunstancias.

Examples:

- I used to study only mechanical engineering, but now I also study programming.  
    Antes solamente estudiaba ingeniería mecánica, pero ahora también estudio programación.
    
- I used to work with physical equipment, but now I work more with digital systems.  
    Antes trabajaba con equipos físicos, pero ahora trabajo más con sistemas digitales.
    
- We used to store information in spreadsheets, but now we use a database.  
    Antes almacenábamos información en hojas de cálculo, pero ahora utilizamos una base de datos.
    

Esta estructura es muy útil en conversaciones profesionales y entrevistas.

## 4. Would para hábitos del pasado

### 4.1 ¿Qué significa?

**Would** puede expresar acciones que se repetían habitualmente en el pasado.

En este contexto se parece a _used to_ y puede traducirse como "solía".

Examples:

- When I was a child, I would play outside every afternoon.  
    Cuando era niño, solía jugar afuera todas las tardes.
    
- Every summer, we would visit my grandparents.  
    Cada verano solíamos visitar a mis abuelos.
    
- My teacher would tell us interesting stories.  
    Mi profesor solía contarnos historias interesantes.
    

La estructura es especialmente natural cuando estamos contando recuerdos o describiendo rutinas de una etapa anterior.

### 4.2 Estructura afirmativa

`Subject + would + base form of the verb + complement`

|Subject|Structure|Example|
|---|---|---|
|I|would work|I would work every Saturday.|
|You|would study|You would study at night.|
|He|would visit|He would visit us.|
|She|would read|She would read every evening.|
|We|would travel|We would travel together.|
|They|would play|They would play football.|

Contracción:

- I would = I'd.
    
- You would = You'd.
    
- He would = He'd.
    
- She would = She'd.
    
- We would = We'd.
    
- They would = They'd.
    

La misma forma verbal se utiliza para todos los sujetos.

### 4.3 Would y el contexto pasado

A diferencia de _used to_, normalmente necesitamos que el contexto pasado esté establecido.

Example:

When I was in school, I would study in the library after classes.

Cuando estaba en la escuela, solía estudiar en la biblioteca después de clases.

La frase _When I was in school_ establece el periodo pasado. Después podemos utilizar _would_ para describir una rutina repetida.

Sin ese contexto, _would_ puede interpretarse como una situación hipotética o condicional.

Por ejemplo:

- I would work there.  
    Trabajaría allí / Trabajaría ahí bajo determinada condición.
    

El significado depende del contexto.

## 5. Diferencias entre Used to y Would

Aunque ambas estructuras pueden describir hábitos pasados, existe una diferencia fundamental.

|Característica|Used to|Would|
|---|---|---|
|Hábitos repetidos|Sí|Sí|
|Estados pasados|Sí|Generalmente no|
|Acciones habituales|Sí|Sí|
|Necesita contexto pasado|No necesariamente|Normalmente sí|
|Contraste con el presente|Muy habitual|No necesariamente explícito|
|Uso en recuerdos y narraciones|Sí|Muy natural|

### 5.1 Cuando ambas estructuras son posibles

Example:

When I was a child, I used to play football every weekend.

When I was a child, I would play football every weekend.

Ambas significan:

Cuando era niño, solía jugar fútbol todos los fines de semana.

La primera presenta el hábito pasado de manera directa.

La segunda tiene un tono más narrativo y puede evocar recuerdos.

### 5.2 Cuando solamente Used to es apropiado

Para expresar estados pasados utilizamos normalmente _used to_.

Examples:

- I used to be shy.  
    Antes era tímido.
    
- She used to know the answer.  
    Antes conocía la respuesta.
    
- They used to own a small company.  
    Antes eran propietarios de una pequeña empresa.
    

No utilizamos normalmente _would_ con estos verbos cuando queremos expresar estados habituales.

Incorrecto en este significado:

- I would be shy when I was a child.
    

Natural:

- I used to be shy when I was a child.
    

La oración con _would_ podría ser correcta en otro contexto, por ejemplo para expresar una conducta recurrente o una situación hipotética, pero no es la opción habitual para describir un estado pasado.

### 5.3 Cuándo elegir cada una

- Utiliza **used to** cuando quieras describir un hábito o estado anterior.
    
- Utiliza **would** cuando quieras narrar acciones repetidas dentro de un periodo pasado ya establecido.
    
- Si tienes dudas, **used to** es generalmente la opción más sencilla para expresar hábitos y estados anteriores.
    

## 6. Used to vs Be used to vs Get used to

Estas tres expresiones parecen similares, pero tienen significados y estructuras diferentes.

Es fundamental no confundirlas.

### 6.1 Used to: hábito o estado pasado

`Subject + used to + base verb`

Significa que algo ocurría habitualmente antes.

Example:

- I used to wake up early.  
    Antes me despertaba temprano.
    

### 6.2 Be used to: estar acostumbrado

`Subject + be + used to + noun / verb-ing`

Significa que algo resulta familiar o habitual para una persona.

Examples:

- I am used to waking up early.  
    Estoy acostumbrado a despertarme temprano.
    
- She is used to working under pressure.  
    Ella está acostumbrada a trabajar bajo presión.
    
- We are used to using different software tools.  
    Estamos acostumbrados a utilizar diferentes herramientas de software.
    

Observa que después de _be used to_ utilizamos un sustantivo o un verbo terminado en -ing.

Incorrecto:

- I am used to wake up early.
    

Correcto:

- I am used to waking up early.
    

### 6.3 Get used to: acostumbrarse

`Subject + get + used to + noun / verb-ing`

Expresa el proceso de adaptación a una situación.

Examples:

- I am getting used to my new job.  
    Me estoy acostumbrando a mi nuevo trabajo.
    
- He got used to working remotely.  
    Se acostumbró a trabajar de manera remota.
    
- You will get used to the new system.  
    Te acostumbrarás al nuevo sistema.
    

### 6.4 Tabla comparativa

|Expresión|Significado|Ejemplo|
|---|---|---|
|Used to|Antes hacía algo|I used to work at night.|
|Be used to|Estar acostumbrado|I am used to working at night.|
|Get used to|Acostumbrarse|I got used to working at night.|

Observa la diferencia:

- I used to work at night.  
    Antes trabajaba de noche. (Hábito pasado)
    
- I am used to working at night.  
    Estoy acostumbrado a trabajar de noche. (Situación actual)
    
- I am getting used to working at night.  
    Me estoy acostumbrando a trabajar de noche. (Proceso de adaptación)
    

## 7. Used to y Would en contextos profesionales

### 7.1 Experiencia laboral

- I used to work with mechanical equipment.  
    Antes trabajaba con equipo mecánico.
    
- I used to coordinate maintenance activities.  
    Antes coordinaba actividades de mantenimiento.
    
- When I worked in that department, I would prepare reports every week.  
    Cuando trabajaba en ese departamento, solía preparar informes cada semana.
    

### 7.2 Tecnología y programación

- I used to manage information in Excel spreadsheets.  
    Antes gestionaba información en hojas de cálculo de Excel.
    
- We used to store our records locally.  
    Antes almacenábamos nuestros registros de manera local.
    
- When I was developing the application, I would test each new feature before releasing it.  
    Cuando desarrollaba la aplicación, solía probar cada nueva funcionalidad antes de publicarla.
    
- The team used to work without an automated reporting system.  
    El equipo antes trabajaba sin un sistema automatizado de reportes.
    

### 7.3 Ingeniería

- The company used to manufacture mechanical components.  
    La empresa antes fabricaba componentes mecánicos.
    
- The technicians would inspect the equipment every morning.  
    Los técnicos solían inspeccionar el equipo todas las mañanas.
    
- We used to perform maintenance manually.  
    Antes realizábamos el mantenimiento manualmente.
    

### 7.4 Entrevistas profesionales

Estas estructuras permiten explicar cómo ha evolucionado tu experiencia.

Examples:

- I used to focus mainly on mechanical engineering, but I gradually became interested in software development.  
    Antes me enfocaba principalmente en ingeniería mecánica, pero gradualmente me interesé en el desarrollo de software.
    
- I used to work with spreadsheets, but I later started using databases to organize information.  
    Antes trabajaba con hojas de cálculo, pero después comencé a utilizar bases de datos para organizar la información.
    
- When I worked on automation projects, I would collaborate with technicians to solve technical problems.  
    Cuando trabajaba en proyectos de automatización, solía colaborar con técnicos para resolver problemas técnicos.
    

## 8. Pronunciación

La pronunciación de estas expresiones merece atención porque _used to_ puede sonar diferente de lo que su escritura sugiere.

|Expresión|IPA aproximado|Significado|
|---|---|---|
|Used to|/ˈjuːst tə/|Solía|
|Didn't use to|/ˈdɪd.ənt ˈjuːs tə/|Antes no solía|
|Would|/wʊd/|Solía / haría, según contexto|
|Wouldn't|/ˈwʊd.ənt/|No solía / no haría|
|Be used to|/biː ˈjuːst tə/|Estar acostumbrado|
|Get used to|/ɡet ˈjuːst tə/|Acostumbrarse|

En el habla rápida, _used to_ suele presentar una pronunciación conectada similar a /ˈjuːstə/.

No confundas:

- _Used to work:_ /ˈjuːst tə wɜːrk/
    
- _Used to working:_ /ˈjuːst tə ˈwɜːrkɪŋ/
    

La primera estructura habla de un hábito pasado. La segunda puede expresar que alguien está acostumbrado a trabajar, dependiendo de si aparece con _be_ o _get_.

## 9. Errores frecuentes de hispanohablantes

### Error 1. Utilizar el pasado después de Used to

Incorrecto:

- I used to worked here.
    

Correcto:

- I used to work here.
    

Después de _used to_ utilizamos la forma base.

### Error 2. Utilizar Used to después de Did

Incorrecto:

- Did you used to live here?
    

Correcto:

- Did you use to live here?
    

El auxiliar _did_ ya expresa el pasado.

### Error 3. Confundir Used to con Be used to

Incorrecto para expresar un hábito pasado:

- I am used to work here.
    

Correcto:

- I used to work here.
    

Si queremos decir que estamos acostumbrados a trabajar aquí:

- I am used to working here.
    

### Error 4. Utilizar Would para estados

Poco natural:

- I would know the manager when I was younger.
    

Natural:

- I used to know the manager when I was younger.
    

### Error 5. Utilizar Would sin contexto

Una oración como:

- I would visit my grandparents.
    

Puede interpretarse como una situación hipotética o condicional.

Es más claro establecer el contexto:

- When I was a child, I would visit my grandparents every summer.
    

### Error 6. Utilizar Would para una acción única

_Would_ en este uso describe acciones repetidas, no un acontecimiento aislado.

Para una acción que ocurrió una sola vez, normalmente utilizamos Past Simple.

- I visited London in 2023.  
    Visité Londres en 2023.
    

No:

- I would visit London in 2023.
    

La segunda construcción podría funcionar en un contexto hipotético o narrativo especial, pero no es la forma habitual de expresar un viaje realizado.

## 10. Comparación con Past Simple

También podemos utilizar Past Simple para hablar de hábitos pasados, especialmente cuando especificamos una frecuencia o un periodo.

Examples:

- I worked every Saturday when I was a student.
    
- I used to work every Saturday when I was a student.
    
- When I was a student, I would work every Saturday.
    

Las tres pueden describir una rutina pasada.

Sin embargo, existen matices:

|Tiempo o estructura|Característica|
|---|---|
|Past Simple|Presenta el hecho o hábito en un periodo pasado.|
|Used to|Destaca que el hábito o estado pertenecía al pasado y generalmente cambió.|
|Would|Presenta acciones repetidas con un tono narrativo o de recuerdo.|

## 11. Narración integrada

**English:**

When I was younger, I used to spend a lot of time learning about mechanical systems. I was particularly interested in machines and automation. During that period, I would read technical documents and look for ways to improve different processes.

I used to focus mainly on mechanical engineering, but over time I became interested in programming and data management. I started learning Python and SQL because I wanted to understand how software could help organize information and solve practical problems.

**Español:**

Cuando era más joven, solía dedicar mucho tiempo a aprender sobre sistemas mecánicos. Me interesaban especialmente las máquinas y la automatización. Durante ese periodo, solía leer documentos técnicos y buscar maneras de mejorar diferentes procesos.

Antes me enfocaba principalmente en ingeniería mecánica, pero con el tiempo me interesé en la programación y la gestión de datos. Comencé a aprender Python y SQL porque quería entender cómo el software podía ayudar a organizar información y resolver problemas prácticos.

**Análisis:**

- _Used to spend:_ hábito anterior.
    
- _Used to be interested:_ estado anterior.
    
- _Would read:_ acción repetida dentro de un periodo pasado establecido.
    
- _Used to focus:_ situación habitual anterior.
    
- _Became:_ acontecimiento que marca un cambio.
    
- _Started:_ acontecimiento que marca el comienzo de una nueva actividad.
    

## 12. Resumen general

|Estructura|Función|Ejemplo|
|---|---|---|
|Used to + base verb|Hábito pasado|I used to study English.|
|Used to + base verb|Estado pasado|I used to be shy.|
|Would + base verb|Acción repetida pasada|I would study every night.|
|Be used to + noun / verb-ing|Estar acostumbrado|I am used to studying.|
|Get used to + noun / verb-ing|Acostumbrarse|I got used to studying.|
|Past Simple|Acción o hábito pasado|I studied every night.|

**Regla fundamental:**

- Para hábitos y estados anteriores: _used to_.
    
- Para acciones repetidas dentro de una narración pasada: _would_.
    
- Para expresar familiaridad con una situación: _be used to_.
    
- Para expresar adaptación: _get used to_.
