# Zero Conditional

## 1. Introducción a los Conditionals

Los **Conditionals** son estructuras gramaticales que permiten expresar relaciones entre una condición y su resultado.

En español utilizamos expresiones como:

- Si estudias, aprendes.
    
- Si llueve, la carretera se moja.
    
- Si no hay electricidad, el equipo no funciona.
    
- Si presionas este botón, el sistema se reinicia.
    

En inglés, estas relaciones se construyen mediante estructuras condicionales.

Ejemplos:

- If you study, you learn.
    
- If it rains, the road gets wet.
    
- If there is no electricity, the equipment doesn't work.
    
- If you press this button, the system restarts.
    

La palabra más característica de estas estructuras es **if**, que significa "si" cuando introduce una condición.

Existen diferentes tipos de condicionales. Cada uno expresa una relación distinta entre la condición y el resultado.

Los principales son:

|Conditional|Función general|
|---|---|
|Zero Conditional|Verdades generales y resultados habituales|
|First Conditional|Posibilidades reales o probables en el futuro|
|Second Conditional|Situaciones hipotéticas o poco probables|
|Third Conditional|Situaciones hipotéticas del pasado|
|Mixed Conditionals|Condiciones y resultados en diferentes referencias temporales|

En este documento estudiaremos el primero: Zero Conditional.

---

## 2. ¿Qué es Zero Conditional?

El **Zero Conditional** se utiliza para expresar situaciones en las que una condición produce un resultado habitual, general o predecible.

Se emplea para comunicar:

- Verdades generales.
    
- Hechos científicos.
    
- Reglas.
    
- Instrucciones.
    
- Relaciones de causa y efecto.
    
- Comportamientos habituales de personas, sistemas o equipos.
    

La característica principal es que tanto la condición como el resultado se expresan normalmente en **Present Simple**.

### Ejemplos

- If you heat water to 100°C at standard atmospheric pressure, it boils.
    

Si calientas agua a 100 °C a presión atmosférica estándar, hierve.

- If people don't sleep enough, they feel tired.
    

Si las personas no duermen lo suficiente, se sienten cansadas.

- If you disconnect the power supply, the machine stops.
    

Si desconectas la alimentación eléctrica, la máquina se detiene.

- If a database receives invalid data, the application may produce an error.
    

Si una base de datos recibe información no válida, la aplicación puede producir un error.

La relación entre condición y resultado se presenta como algo generalmente cierto, no como una predicción de un acontecimiento futuro específico.

---

## 3. Estructura gramatical

La estructura general es:

**If + Present Simple, Present Simple.**

También puede utilizarse el orden inverso:

**Present Simple + if + Present Simple.**

### 3.1 Estructura afirmativa

|Parte|Estructura|
|---|---|
|Condition|If + subject + Present Simple|
|Result|Subject + Present Simple|

Ejemplos:

- If I exercise, I feel better.
    
- If water freezes, it becomes ice.
    
- If the temperature increases, the metal expands.
    
- If the server receives a request, it processes the information.
    

### 3.2 Estructura negativa

Podemos utilizar oraciones negativas en cualquiera de las dos partes.

Ejemplos:

- If you don't study, you don't improve.
    
- If the system doesn't receive power, it doesn't start.
    
- If employees don't follow the procedure, errors occur.
    
- If the machine doesn't receive maintenance, its performance decreases.
    

Recuerda las estructuras negativas del Present Simple:

- I / You / We / They + don't + base verb.
    
- He / She / It + doesn't + base verb.
    

El verbo principal permanece en su forma base después de `don't` y `doesn't`.

### 3.3 Estructura interrogativa

También podemos formular preguntas utilizando Zero Conditional.

Ejemplos:

- What happens if you heat ice?
    
- What happens if the server stops working?
    
- What do you do if the machine produces an error?
    
- What happens if employees don't follow the procedure?
    

La estructura de las preguntas depende del tipo de interrogativo y del auxiliar correspondiente.

|Tipo|Ejemplo|
|---|---|
|What happens if...?|What happens if the temperature increases?|
|What do you do if...?|What do you do if the system fails?|
|What happens when...?|What happens when the battery is empty?|
|Does it work if...?|Does it work if the internet connection fails?|

## 4. Las dos partes de una oración condicional

Una oración condicional tiene dos componentes principales.

### If-clause

Es la parte que presenta la condición.

Ejemplo:

- If the temperature increases...
    

Si la temperatura aumenta...

### Main clause

Es la parte que presenta el resultado.

Ejemplo:

- The metal expands.
    

El metal se expande.

### Oración completa

- If the temperature increases, the metal expands.
    

Si la temperatura aumenta, el metal se expande.

### Representación

|Componente|Ejemplo|Función|
|---|---|---|
|If-clause|If the temperature increases|Presenta la condición|
|Main clause|The metal expands|Presenta el resultado|

La condición y el resultado pueden cambiar de posición sin modificar el significado fundamental.

- If the temperature increases, the metal expands.
    
- The metal expands if the temperature increases.
    

### Regla de puntuación

Cuando la oración comienza con `if-clause`, normalmente utilizamos una coma para separar las dos partes.

- If you press the button, the system starts.
    

Cuando la condición aparece al final, generalmente no necesitamos coma.

- The system starts if you press the button.

## 5. Usos principales del Zero Conditional

### 5.1 Verdades generales

Se utiliza para expresar hechos que se consideran generalmente verdaderos.

Ejemplos:

- If the sun sets, it gets dark.
    
- If people don't drink water, they become dehydrated.
    
- If you mix blue and yellow, you get green.
    
- If plants don't receive enough light, their growth slows down.
    

No describimos un acontecimiento particular. Comunicamos una relación general.

### 5.2 Hechos científicos

Es frecuente en explicaciones científicas, matemáticas y técnicas.

Ejemplos:

- If water reaches its boiling point, it changes into vapor.
    
- If an object falls near Earth's surface, gravity accelerates it downward.
    
- If electrical resistance increases while voltage remains constant, current decreases.
    
- If pressure increases in a closed system, the behavior of the gas changes.
    

En contextos científicos, la precisión depende de las condiciones establecidas. Por ejemplo, el punto de ebullición del agua depende de la presión atmosférica.

### 5.3 Reglas y procedimientos

Se utiliza para expresar instrucciones o consecuencias establecidas.

Ejemplos:

- If you enter the wrong password, the system rejects the login.
    
- If an employee loses an access card, they report the incident.
    
- If the equipment shows an alarm, the operator checks the control panel.
    
- If a document contains incorrect information, the department requests a correction.
    

### 5.4 Comportamientos habituales

También describe cómo responde una persona ante determinadas circunstancias.

Ejemplos:

- If I feel tired, I take a break.
    
- If she has a problem, she asks for help.
    
- If we have a meeting, we prepare the documents.
    
- If he doesn't understand something, he asks questions.
    

### 5.5 Relaciones de causa y efecto

Permite explicar qué sucede cuando se presenta una condición.

Ejemplos:

- If the battery loses power, the device shuts down.
    
- If the network connection fails, the application stops communicating with the server.
    
- If the engine overheats, its performance decreases.
    
- If the database receives incomplete information, the report may contain errors.

## 6. If vs When

Las palabras `if` y `when` pueden introducir condiciones, pero no expresan exactamente la misma idea.

### If

Significa "si".

Presenta una condición cuya ocurrencia no se da por segura.

- If it rains, we stay inside.
    

Si llueve, nos quedamos dentro.

La lluvia se presenta como una posibilidad o condición.

### When

Significa "cuando".

Se utiliza cuando hablamos de algo que sucede habitualmente o que consideramos esperado.

- When it rains, the roads get wet.
    

Cuando llueve, las carreteras se mojan.

La oración presenta una relación general.

### Comparación

|If|When|
|---|---|
|Presenta una condición|Presenta una situación esperada o recurrente|
|If I have time, I read.|When I have time, I read.|
|Si tengo tiempo, leo.|Cuando tengo tiempo, leo.|

La diferencia depende del contexto. `If` no significa necesariamente que algo sea improbable, y `when` no garantiza por sí solo que un acontecimiento ocurrirá en el futuro.

### Ejemplos profesionales

- If the server fails, the system sends an alert.
    
- When the server fails, the system sends an alert.
    

La primera presenta una condición. La segunda puede describir un comportamiento esperado cada vez que ocurre esa falla.

---

## 7. Unless: una alternativa a If... not

`Unless` significa "a menos que" o "si no".

Se utiliza para expresar una condición negativa.

### Comparación

- If you don't maintain the machine, it deteriorates.
    
- Unless you maintain the machine, it deteriorates.
    

Si no das mantenimiento a la máquina, se deteriora.

### Ejemplos

- Unless you practice, you don't improve.
    

A menos que practiques, no mejoras.

- The system doesn't start unless you enter the correct password.
    

El sistema no inicia a menos que ingreses la contraseña correcta.

- Unless employees follow the procedure, errors occur.
    

A menos que los empleados sigan el procedimiento, ocurren errores.

### Estructura

**Unless + affirmative clause, main clause.**

Aunque `unless` tiene un significado negativo, normalmente no agregamos `not` en la misma cláusula.

Incorrecto en el significado pretendido:

- Unless you don't study, you don't improve.
    

Correcto:

- Unless you study, you don't improve.
    

No obstante, debemos analizar el sentido de la oración antes de reemplazar automáticamente `if...not` por `unless`, porque no todas las construcciones negativas son equivalentes en cualquier contexto.

## 8. Uso de Can, May y Must en Zero Conditional

Aunque la estructura básica utiliza Present Simple en ambas partes, también podemos incorporar verbos modales para expresar capacidad, posibilidad, permiso u obligación.

### Can

Expresa capacidad o posibilidad.

- If you press this button, you can restart the system.
    
- If employees have access, they can view the records.
    
- If the device connects to the network, it can send information.
    

### May

Expresa posibilidad.

- If the temperature increases, the equipment may overheat.
    
- If the input data is incorrect, the application may produce an error.
    

### Must

Expresa obligación o necesidad.

- If employees use company equipment, they must follow the safety procedures.
    
- If a machine produces an alarm, operators must check the system.
    

### Tabla

|Modal|Función|Ejemplo|
|---|---|---|
|Can|Capacidad o posibilidad|If you connect the device, it can communicate.|
|May|Posibilidad|If the server fails, data may be unavailable.|
|Must|Obligación|If an alarm appears, operators must respond.|

Estas construcciones amplían el Zero Conditional sin cambiar su función general.

## 9. Zero Conditional en ingeniería y tecnología

Este condicional resulta especialmente útil para explicar procesos, sistemas, procedimientos y comportamientos técnicos.

### 9.1 Ingeniería mecánica

- If friction increases, energy losses increase.
    
- If a bearing lacks lubrication, its temperature rises.
    
- If the engine overheats, its performance decreases.
    
- If a component receives excessive load, it may deform.
    
- If vibration increases, the equipment may require inspection.
    

### 9.2 Electricidad y electrónica

- If voltage increases while resistance remains constant, current increases.
    
- If a circuit is open, current doesn't flow through that path.
    
- If the power supply fails, the equipment shuts down.
    
- If a fuse blows, the circuit becomes interrupted.
    

### 9.3 Desarrollo de software

- If a user enters valid credentials, the system grants access.
    
- If the application receives invalid data, it displays an error.
    
- If the database connection fails, the application cannot retrieve information.
    
- If a developer changes the source code, the application behaves differently depending on the changes.
    

### 9.4 Bases de datos

- If a query contains an invalid table name, PostgreSQL returns an error.
    
- If a primary key is duplicated, the database rejects the insertion.
    
- If a record is deleted, the database removes that record according to the operation and its constraints.
    
- If a query filters the records by date, the result contains only the matching records.
    

### 9.5 Administración y procesos operativos

- If a vehicle requires maintenance, the department registers the request.
    
- If an inventory record contains incorrect information, the responsible employee reviews it.
    
- If a unit is involved in an incident, the department documents the event.
    
- If a report is incomplete, the responsible area requests additional information.
    

Estas oraciones son útiles para describir procedimientos y explicar el funcionamiento de procesos reales.

## 10. Diferencias entre Zero Conditional y First Conditional

Esta distinción es fundamental porque ambos utilizan `if`, pero su significado es diferente.

### Zero Conditional

Expresa hechos generales, reglas y resultados habituales.

Estructura:

**If + Present Simple, Present Simple.**

Ejemplo:

- If you heat ice, it melts.
    

Si calientas hielo, se derrite.

### First Conditional

Expresa una posibilidad real o probable en el futuro.

Estructura básica:

**If + Present Simple, will + base verb.**

Ejemplo:

- If it rains tomorrow, we will stay home.
    

Si llueve mañana, nos quedaremos en casa.

### Comparación

|Zero Conditional|First Conditional|
|---|---|
|If the temperature rises, ice melts.|If the temperature rises tomorrow, we will stop the process.|
|Si aumenta la temperatura, el hielo se derrite.|Si aumenta la temperatura mañana, detendremos el proceso.|
|Hecho general|Posibilidad futura concreta|

### Otro ejemplo

**Zero Conditional**

- If I work late, I feel tired.
    

Si trabajo hasta tarde, me siento cansado.

Describe una respuesta habitual.

**First Conditional**

- If I work late tonight, I will feel tired tomorrow.
    

Si trabajo hasta tarde esta noche, me sentiré cansado mañana.

Describe una situación futura específica.

### Diferencia esencial

No debemos seleccionar el condicional solamente porque la oración contiene `if`.

Primero debemos determinar si estamos hablando de:

- Una relación general o habitual.
    
- Una posibilidad real en el futuro.

## 11. Errores frecuentes

|Error|Forma correcta|Explicación|
|---|---|---|
|If you heats water, it boils.|If you heat water, it boils.|Con you se utiliza la forma base.|
|If he work hard, he improves.|If he works hard, he improves.|Tercera persona singular.|
|If the system don't work, it stops.|If the system doesn't work, it stops.|Se utiliza doesn't con it.|
|If you will heat water, it boils.|If you heat water, it boils.|No se necesita will en la condición del Zero Conditional.|
|If I am tired, I will take a break.|If I am tired, I take a break.|La segunda expresa un hábito general; la primera es First Conditional.|
|Unless you don't study, you fail.|Unless you study, you fail.|Unless ya expresa una condición negativa.|
|If the machine fail, it stops.|If the machine fails, it stops.|La tercera persona singular requiere -s.|
|If water freeze, it becomes ice.|If water freezes, it becomes ice.|Se necesita la forma correcta del verbo.|

### Errores conceptuales

**Error 1: utilizar siempre Zero Conditional después de if.**

No todas las oraciones con `if` son Zero Conditional.

- If I have time, I read. (hábito)
    
- If I have time tomorrow, I will read. (posibilidad futura)
    

**Error 2: pensar que el resultado siempre es completamente seguro.**

El Zero Conditional describe relaciones generales o habituales. Cuando el resultado depende de otros factores, podemos utilizar `may`, `can` o expresiones de probabilidad.

- If the server receives too many requests, it may become slower.
    

**Error 3: confundir una regla general con una situación específica.**

- If employees arrive late, the supervisor records the incident. (procedimiento general)
    
- If an employee arrives late tomorrow, the supervisor will speak to them. (situación futura específica)

## 13. Narración integradora

### English text

I work with technical information and operational processes.

If I receive a new request, I review the available documentation.

If the information is incomplete, I ask for the missing details.

When a vehicle requires maintenance, the responsible department registers the request.

If the equipment has a technical problem, the team evaluates the situation and identifies possible causes.

If the problem affects operations, the department coordinates the necessary actions.

In software development, if an application receives incorrect information, it may produce unexpected results.

If developers validate the input data, they reduce the possibility of errors.

These procedures help organizations maintain reliable information and improve their operations.

### Traducción

Trabajo con información técnica y procesos operativos.

Si recibo una nueva solicitud, reviso la documentación disponible.

Si la información está incompleta, solicito los datos faltantes.

Cuando un vehículo requiere mantenimiento, el departamento responsable registra la solicitud.

Si el equipo presenta un problema técnico, el equipo evalúa la situación e identifica las posibles causas.

Si el problema afecta las operaciones, el departamento coordina las acciones necesarias.

En el desarrollo de software, si una aplicación recibe información incorrecta, puede producir resultados inesperados.

Si los desarrolladores validan los datos de entrada, reducen la posibilidad de errores.

Estos procedimientos ayudan a las organizaciones a mantener información confiable y mejorar sus operaciones.

### Análisis gramatical

|Oración|If-clause|Main clause|
|---|---|---|
|If I receive a new request, I review the documentation.|If I receive a new request|I review the documentation|
|If the information is incomplete, I ask for details.|If the information is incomplete|I ask for details|
|If the equipment has a problem, the team evaluates it.|If the equipment has a problem|The team evaluates it|
|If the application receives incorrect information, it may produce errors.|If the application receives incorrect information|It may produce errors|
|If developers validate the data, they reduce errors.|If developers validate the data|They reduce errors|

## 14. Resumen general

|Elemento|Característica|
|---|---|
|Nombre|Zero Conditional|
|Función|Verdades generales, reglas y resultados habituales|
|Condición|Present Simple|
|Resultado|Present Simple, o modal + base verb|
|Conector principal|If|
|Alternativa|When|
|Alternativa negativa|Unless|
|Referencia temporal|General o habitual|
|Ejemplo|If you heat water, it boils.|

### Fórmula principal

**If + Present Simple, Present Simple.**

### Conceptos que debemos recordar

1. Zero Conditional expresa relaciones generales entre condiciones y resultados.
    
2. Normalmente utiliza Present Simple en ambas partes.
    
3. Puede expresar hechos científicos, procedimientos y hábitos.
    
4. `If` introduce una condición.
    
5. `When` presenta una situación esperada o recurrente.
    
6. `Unless` puede sustituir algunas estructuras con `if...not`.
    
7. Podemos incorporar `can`, `may` y `must`.
    
8. No debemos confundir Zero Conditional con First Conditional.
    
9. La elección depende del significado que queremos comunicar.
