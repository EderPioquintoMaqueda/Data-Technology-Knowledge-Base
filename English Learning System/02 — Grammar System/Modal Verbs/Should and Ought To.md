# Should and Ought To

## 1. Introduction: Advice and recommendations

`Should` y `ought to` son estructuras que utilizamos principalmente para expresar consejos, recomendaciones, expectativas y obligaciones moderadas.

En español pueden traducirse como:

- Deberías...
    
- Debería...
    
- Conviene que...
    
- Lo recomendable sería...
    
- Tendrías que...
    

Examples:

|English|Spanish|
|---|---|
|You should study English.|Deberías estudiar inglés.|
|We should improve the process.|Deberíamos mejorar el proceso.|
|He ought to apologize.|Él debería disculparse.|
|Employees should follow the procedure.|Los empleados deberían seguir el procedimiento.|
|You shouldn't worry.|No deberías preocuparte.|

Aunque ambos tienen significados similares, `should` es mucho más frecuente en el inglés cotidiano.

## 2. SHOULD: Fundamental characteristics

`Should` es un modal verb y sigue las reglas generales de los modales.

### 2.1. Affirmative structure

**Subject + should + base verb + complement.**

Examples:

- I should study.
    
- You should rest.
    
- He should work harder.
    
- She should learn Python.
    
- We should review the information.
    
- They should arrive early.
    

Después de `should`, el verbo principal aparece en su forma base.

|Correct|Incorrect|
|---|---|
|She should work.|She should works.|
|He should study.|He should studies.|
|We should improve.|We should to improve.|
|They should arrive.|They should arrived.|

### 2.2. No conjugation

`Should` no cambia según el sujeto.

|Subject|Structure|
|---|---|
|I|should work|
|You|should work|
|He|should work|
|She|should work|
|It|should work|
|We|should work|
|They|should work|

No agregamos `-s` en tercera persona.

### 2.3. Negative structure

La negación se construye agregando `not` después de `should`.

**Subject + should not + base verb.**

La contracción más común es:

`Should not` → `Shouldn't`

Examples:

- You shouldn't smoke.
    
- He shouldn't drive so fast.
    
- We shouldn't ignore the problem.
    
- Employees shouldn't share passwords.
    
- The company shouldn't delay the project.
    

### 2.4. Interrogative structure

Para formular preguntas, colocamos `should` antes del sujeto.

**Should + subject + base verb + complement?**

Examples:

- Should I study more?
    
- Should we leave now?
    
- Should he apply for the position?
    
- Should they change the schedule?
    

No utilizamos `do` o `does`.

Incorrect: `Do you should study?`

Correct: `Should you study?`

## 3. SHOULD: Giving advice

El uso más frecuente de `should` es dar consejos.

Lo utilizamos cuando consideramos que una acción es conveniente, beneficiosa o recomendable.

Examples:

- You should get more sleep.
    
- You should exercise regularly.
    
- You should organize your time.
    
- You should practice English every day.
    
- You should save some money.
    

La recomendación no necesariamente representa una obligación. La persona conserva la libertad de decidir si sigue el consejo.

### 3.1. Personal advice

Examples:

- I think you should take a break.
    
- You should talk to your manager.
    
- You should consider another option.
    
- You should focus on your professional development.
    
- You should be more careful.
    

### 3.2. Advice about work

Examples:

- You should review the report before sending it.
    
- We should organize the documentation.
    
- The team should improve communication.
    
- Employees should protect confidential information.
    
- You should prepare for the interview.
    

### 3.3. Giving advice with I think

Una forma natural de suavizar una recomendación es comenzar con `I think`.

Examples:

- I think you should apply for the position.
    
- I think we should review the database.
    
- I think she should talk to the manager.
    
- I think they should consider another solution.
    

También podemos utilizar:

- I believe you should...
    
- In my opinion, we should...
    
- I would recommend that...
    
- It would be better to...
    

Estas expresiones permiten comunicar recomendaciones de forma profesional y diplomática.

## 4. SHOULD: Asking for advice

`Should` también se utiliza para preguntar qué sería conveniente hacer.

Structure:

**Should + subject + base verb + complement?**

Examples:

- Should I apply for this job?
    
- Should I study Python first?
    
- Should we change the procedure?
    
- Should I contact the manager?
    
- Should they update the software?
    

### 4.1. WH-questions

Podemos combinar `should` con palabras interrogativas.

Examples:

- What should I do?
    
- Where should we go?
    
- When should I send the report?
    
- How should I prepare for the interview?
    
- Which option should we choose?
    
- Why should I change the configuration?
    

Estas estructuras son muy frecuentes en conversaciones cotidianas y profesionales.

### 4.2. Short answers

Las respuestas breves pueden utilizar el modal.

|Question|Affirmative|Negative|
|---|---|---|
|Should I go?|Yes, you should.|No, you shouldn't.|
|Should we wait?|Yes, we should.|No, we shouldn't.|
|Should he apply?|Yes, he should.|No, he shouldn't.|

También podemos responder con expresiones más naturales:

- I think so.
    
- Probably.
    
- I don't think so.
    
- Not necessarily.
    
- It depends.
    

## 5. SHOULD: Recommendations and best practices

`Should` es muy útil para presentar recomendaciones técnicas, administrativas y organizacionales.

Examples:

- The system should include security controls.
    
- Employees should follow the safety procedures.
    
- The database should be backed up regularly.
    
- Reports should contain accurate information.
    
- The company should invest in employee training.
    

En estos contextos, `should` no necesariamente significa que exista una obligación legal. Puede representar una práctica recomendada o un estándar deseable.

### 5.1. Technical recommendations

Examples:

- Developers should write clean code.
    
- We should test the application before deployment.
    
- The server should have sufficient storage.
    
- Users should create strong passwords.
    
- The database should be properly documented.
    

### 5.2. Engineering recommendations

Examples:

- Technicians should inspect the equipment regularly.
    
- Operators should wear protective equipment.
    
- The machine should receive preventive maintenance.
    
- We should check the electrical connections.
    
- The system should operate within the recommended temperature range.
    

## 6. SHOULD: Expectations

`Should` también permite expresar expectativas: algo que esperamos que suceda porque parece razonable, probable o previsto.

Examples:

- The meeting should start at nine.
    
- The package should arrive tomorrow.
    
- The system should work correctly.
    
- She should be at the office now.
    
- The project should finish next month.
    

No siempre estamos dando un consejo. En ocasiones estamos expresando una expectativa.

### 6.1. Should vs. Will

Compare:

- The meeting will start at nine.
    
- The meeting should start at nine.
    

La primera oración presenta el inicio como un hecho futuro esperado o anunciado.

La segunda expresa una expectativa, pero deja abierta la posibilidad de que ocurra algún cambio.

Otros ejemplos:

- The report will be ready tomorrow.
    
- The report should be ready tomorrow.
    

En el segundo caso, el hablante espera que el reporte esté listo, pero no lo garantiza.

## 7. SHOULD: Mild obligation

`Should` también puede expresar una responsabilidad o una obligación moderada.

Examples:

- Employees should arrive on time.
    
- We should respect company policies.
    
- People should protect the environment.
    
- Companies should treat employees fairly.
    

La diferencia respecto a `must` es importante:

- `Must`: obligación fuerte o requisito.
    
- `Should`: recomendación, expectativa o responsabilidad considerada conveniente.
    

Compare:

- You must wear a helmet. (Es obligatorio).
    
- You should wear a helmet. (Es recomendable).
    

En determinados contextos, una recomendación puede ser muy importante, pero no necesariamente constituye una obligación formal.

## 8. SHOULD NOT: Negative recommendations

`Should not` o `shouldn't` expresa que una acción no es recomendable.

Examples:

- You shouldn't smoke.
    
- You shouldn't drive when you're tired.
    
- We shouldn't ignore the problem.
    
- Employees shouldn't share confidential information.
    
- The company shouldn't delay the maintenance.
    

### 8.1. Giving negative advice

Examples:

- You shouldn't spend too much money.
    
- You shouldn't worry about every mistake.
    
- We shouldn't make decisions without information.
    
- You shouldn't send the report without reviewing it.
    

### 8.2. Shouldn't vs. Mustn't

No tienen el mismo significado.

|Shouldn't|Mustn't|
|---|---|
|Recomendación negativa|Prohibición|
|No deberías hacerlo|No debes hacerlo|
|No es recomendable|No está permitido|

Compare:

- You shouldn't use your phone during the meeting.
    
- You mustn't use your phone in this restricted area.
    

La primera oración expresa una recomendación o norma de comportamiento.

La segunda comunica una prohibición.

## 9. OUGHT TO: Advice and recommendations

`Ought to` tiene un significado muy parecido a `should`.

Se utiliza para expresar consejos, recomendaciones, responsabilidades y expectativas.

Examples:

- You ought to study more.
    
- We ought to improve the process.
    
- He ought to apologize.
    
- Employees ought to follow safety procedures.
    
- The company ought to invest in technology.
    

### 9.1. Affirmative structure

**Subject + ought to + base verb + complement.**

Examples:

- I ought to study.
    
- She ought to rest.
    
- We ought to leave early.
    
- They ought to review the report.
    

A diferencia de `should`, `ought to` conserva la preposición `to`.

Incorrect: She ought study.

Correct: She ought to study.

### 9.2. Negative structure

La negación se construye colocando `not` después de `ought`.

**Subject + ought not to + base verb.**

La contracción es:

`Ought not to` → `Oughtn't to`

Examples:

- You ought not to worry.
    
- He ought not to drive so fast.
    
- We ought not to ignore the warning.
    
- Employees ought not to share confidential information.
    

La forma negativa contraída existe, pero es poco frecuente en conversaciones cotidianas.

### 9.3. Interrogative structure

Podemos colocar `ought` antes del sujeto.

**Ought + subject + to + base verb + complement?**

Examples:

- Ought I to apologize?
    
- Ought we to leave now?
    
- Ought he to contact the manager?
    

Estas preguntas son gramaticalmente correctas, pero suenan formales y son menos frecuentes que las preguntas con `should`.

En conversaciones normales preferimos:

- Should I apologize?
    
- Should we leave now?
    
- Should he contact the manager?
    

## 10. SHOULD vs. OUGHT TO

Ambas estructuras expresan recomendaciones y expectativas.

La diferencia principal es su frecuencia y matiz.

- `Should`: es la forma más común, flexible y natural.
    
- `Ought to`: puede transmitir una recomendación basada en principios, responsabilidad o lo que se considera correcto.
    

Examples:

- You should help your colleagues.
    
- You ought to help your colleagues.
    

Ambas son correctas.

La segunda puede transmitir un sentido de responsabilidad moral un poco más marcado, aunque depende del contexto.

### 10.1. Comparison table

|Feature|Should|Ought to|
|---|---|---|
|Advice|Very common|Yes|
|Recommendations|Very common|Yes|
|Expectations|Very common|Yes|
|Moral responsibility|Yes|Often emphasized|
|Negative form|Shouldn't|Ought not to|
|Questions|Very common|Less common|
|Conversational frequency|High|Lower|

**Practical recommendation:** Aprende a utilizar `should` con soltura primero. Reconoce `ought to` cuando lo encuentres en textos o conversaciones.

## 11. SHOULD: Different verb structures

Después de `should` podemos utilizar distintas estructuras para expresar diferentes relaciones temporales y significados.

### 11.1. Should + base verb

Expresa una recomendación o expectativa general.

- You should study.
    
- We should improve the system.
    
- She should attend the meeting.
    

### 11.2. Should + be + adjective or noun

Expresa cómo consideramos que debería ser una situación o condición.

Examples:

- The report should be accurate.
    
- The equipment should be safe.
    
- The system should be reliable.
    
- Employees should be responsible.
    
- The process should be efficient.
    

### 11.3. Should + be + verb-ing

Puede expresar que esperamos que una actividad esté desarrollándose en un momento determinado.

Examples:

- She should be working now.
    
- They should be traveling tomorrow.
    
- The team should be reviewing the information.
    

### 11.4. Should have + past participle

Esta estructura expresa una recomendación o expectativa relacionada con el pasado.

Examples:

- You should have studied more.
    
- I should have called you.
    
- We should have checked the information.
    
- They should have completed the report.
    

Dependiendo del contexto, puede comunicar:

- Una acción que habría sido recomendable realizar.
    
- Un error o una oportunidad perdida.
    
- Una expectativa que probablemente no se cumplió.
    

La estructura es:

**Subject + should + have + past participle.**

Se desarrollará con mayor profundidad en el documento dedicado a los perfect modal verbs.

## 12. SHOULD HAVE: Past advice and criticism

Este uso merece especial atención porque es muy frecuente en conversaciones.

Compare:

- You should study more. (Deberías estudiar más).
    
- You should have studied more. (Deberías haber estudiado más).
    

La segunda oración se refiere a una oportunidad pasada. El hablante considera que habría sido mejor realizar esa acción.

### 12.1. Examples

- I should have prepared better for the interview.
    
- We should have reviewed the documentation.
    
- She should have arrived earlier.
    
- The team should have tested the application.
    
- They should have informed the manager.
    

### 12.2. Expressing regret

También podemos hablar de decisiones pasadas que ahora consideramos equivocadas.

Examples:

- I should have saved more money.
    
- I should have started learning English earlier.
    
- We should have planned the project differently.
    

La estructura permite expresar reflexión, arrepentimiento o crítica constructiva.

### 12.3. Shouldn't have + past participle

Se utiliza para expresar que una acción pasada no debió realizarse.

Examples:

- You shouldn't have said that.
    
- I shouldn't have spent so much money.
    
- We shouldn't have ignored the warning.
    
- They shouldn't have deleted the information.
    

Compare:

|Structure|Meaning|
|---|---|
|Should do|Debería hacerlo|
|Shouldn't do|No debería hacerlo|
|Should have done|Debería haberlo hecho|
|Shouldn't have done|No debería haberlo hecho|

## 13. SHOULD vs. MUST vs. HAVE TO

Es importante distinguir entre una recomendación y una obligación.

|Structure|Main meaning|Example|
|---|---|---|
|Should|Recommendation|You should study.|
|Must|Strong obligation|You must wear a helmet.|
|Have to|Requirement or necessity|I have to attend the meeting.|

### 13.1. Same situation, different intention

Consideramos una situación laboral:

- You should review the report.  
    Es recomendable revisar el reporte.
    
- You must review the report.  
    Es obligatorio revisar el reporte.
    
- You have to review the report.  
    Tienes que revisar el reporte debido a un requisito o circunstancia.
    

El significado depende del contexto, pero esta comparación permite identificar la intención principal.

## 14. SHOULD vs. HAD BETTER

Existe otra expresión importante para dar consejos: `had better`.

Su significado se aproxima a «sería mejor que» o «más vale que».

Examples:

- You had better leave now.
    
- We had better check the information.
    
- You had better prepare for the interview.
    

Aunque contiene la palabra `had`, no es un tiempo pasado. Se utiliza para hablar de situaciones presentes o futuras.

Su estructura es:

**Subject + had better + base verb.**

La forma negativa es:

**Subject + had better not + base verb.**

Examples:

- You had better not be late.
    
- We had better not ignore the warning.
    

### 14.1. Should vs. Had Better

|Should|Had better|
|---|---|
|Recomendación general|Consejo más urgente o enfático|
|You should study.|You had better study.|
|You should leave early.|You had better leave early.|

`Had better` puede sugerir que existirán consecuencias negativas si no se sigue el consejo.

No es tan neutral como `should`.

## 15. Professional English: Technology, Engineering and Business

### 15.1. Technology and software

- Developers should write clean and maintainable code.
    
- We should test the application before deployment.
    
- The database should be backed up regularly.
    
- Users shouldn't share their passwords.
    
- The system should be compatible with different devices.
    
- We should document every important change.
    

### 15.2. Data analysis

- Analysts should verify the quality of the data.
    
- We should remove duplicate records.
    
- The results should be reviewed before publication.
    
- The company should improve its reporting process.
    
- We shouldn't make decisions based on incomplete information.
    

### 15.3. Engineering and machinery

- Technicians should inspect the equipment regularly.
    
- Operators should follow safety procedures.
    
- The machine should receive preventive maintenance.
    
- We shouldn't ignore unusual vibrations.
    
- The electrical connections should be checked.
    
- The equipment should be calibrated periodically.
    

### 15.4. Meetings and teamwork

- We should discuss the project first.
    
- The team should establish clear objectives.
    
- Everyone should understand their responsibilities.
    
- We shouldn't interrupt other participants.
    
- We ought to consider different perspectives.
    

### 15.5. Job interviews

- I think I should continue improving my technical skills.
    
- I should be able to contribute to the team.
    
- Candidates should understand the responsibilities of the position.
    
- Could you explain what skills I should develop?
    
- What should I expect during the selection process?
    

## 16. Common mistakes

|Incorrect|Correct|Explanation|
|---|---|---|
|She should studies.|She should study.|Después del modal utilizamos el verbo base.|
|I should to go.|I should go.|Should no lleva to.|
|He don't should work.|He shouldn't work.|No utilizamos do para negar should.|
|Do you should study?|Should you study?|El modal se coloca antes del sujeto.|
|She ought study.|She ought to study.|Ought conserva to.|
|He oughts to work.|He ought to work.|Ought no se conjuga.|
|I should have went.|I should have gone.|Se utiliza el participio pasado.|
|You shouldn't have to studied.|You shouldn't have studied.|La estructura correcta es shouldn't have + participio.|
|I shoulded work.|I should work.|Should no tiene una forma regular de pasado.|
|You mustn't study. (cuando se quiere decir que no es necesario)|You don't have to study.|Mustn't expresa prohibición.|

## 18. Integrated narrative

### Improving a professional process

**English**

When I joined the department, I realized that we should improve several administrative processes.

First, we should organize the documentation and establish clear responsibilities. Employees should understand the procedures and know where to find the necessary information.

We should also use digital tools to reduce repetitive tasks. The database should be updated regularly, and the information should be reviewed before preparing the reports.

Last month, we discovered an inconsistency in the records. We should have identified the problem earlier, but we hadn't reviewed all the information.

The team shouldn't ignore small errors because they can affect the final results.

I think every department should invest in continuous improvement. Organizations ought to develop efficient processes and support the professional development of their employees.

**Español**

Cuando me incorporé al departamento, me di cuenta de que deberíamos mejorar varios procesos administrativos.

Primero, deberíamos organizar la documentación y establecer responsabilidades claras. Los empleados deberían comprender los procedimientos y saber dónde encontrar la información necesaria.

También deberíamos utilizar herramientas digitales para reducir las tareas repetitivas. La base de datos debería actualizarse regularmente y la información tendría que revisarse antes de preparar los reportes.

El mes pasado descubrimos una inconsistencia en los registros. Deberíamos haber identificado el problema antes, pero no habíamos revisado toda la información.

El equipo no debería ignorar los errores pequeños porque pueden afectar los resultados finales.

Considero que cada departamento debería invertir en mejora continua. Las organizaciones deberían desarrollar procesos eficientes y apoyar el desarrollo profesional de sus empleados.

## 21. Essential rules to remember

1. `Should` es un modal verb y no cambia según el sujeto.
    
2. Después de `should` utilizamos el verbo en su forma base.
    
3. `Shouldn't` expresa una recomendación negativa.
    
4. `Should` permite dar y solicitar consejos.
    
5. También expresa expectativas y responsabilidades moderadas.
    
6. `Ought to` tiene un significado muy parecido a `should`.
    
7. `Ought to` conserva la preposición `to`.
    
8. `Should` es más frecuente en conversaciones cotidianas.
    
9. `Should have + past participle` permite expresar consejos relacionados con el pasado, arrepentimientos o críticas.
    
10. `Shouldn't have + past participle` indica que una acción pasada no debió realizarse.
    
11. `Must` expresa una obligación más fuerte que `should` en muchos contextos.
    
12. `Had better` expresa una recomendación más urgente o enfática.

## Final learning principle

La diferencia fundamental es:

- **SHOULD:** debería hacerlo; es recomendable o conveniente.
    
- **SHOULDN'T:** no debería hacerlo; no es recomendable.
    
- **OUGHT TO:** debería hacerlo; existe una responsabilidad o expectativa.
    
- **SHOULD HAVE:** debería haberlo hecho; era recomendable realizarlo en el pasado.
    
- **HAD BETTER:** más vale que lo haga; existe una razón importante para seguir el consejo.
    

Estas estructuras te permitirán expresar opiniones, recomendaciones y responsabilidades sin confundirlas con obligaciones estrictas.
