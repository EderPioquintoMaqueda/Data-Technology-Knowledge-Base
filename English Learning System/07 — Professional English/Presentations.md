# 📊 Presentations in English (Presenting Data)

## 1. Structure
1. **Hook & purpose** — *Today I'll show you how we cut report time by 90%.*
2. **Agenda** — *First…, then…, finally…*
3. **Body** — context → data → insight → recommendation.
4. **Conclusion** — key message + call to action.
5. **Q&A**.

## 2. Signposting language
| Function | Phrases |
|---|---|
| Open | *Good morning, everyone. Thank you for coming. My name is… and I'm a data analyst on the… team.* |
| Purpose | *The purpose of this presentation is to… / Today I'd like to talk about…* |
| Agenda | *I've divided my talk into three parts.* |
| Move on | *Moving on to… / Let's now turn to… / That brings me to my next point.* |
| Refer to a visual | *As you can see on this slide… / If you look at the chart on the left…* |
| Emphasise | *What's really important here is… / I'd like to highlight…* |
| Example | *To give you an example… / Take, for instance,…* |
| Summarise | *So, to recap… / In a nutshell…* |
| Conclude | *To conclude… / The key takeaway is… / My recommendation is…* |
| Q&A | *I'd be happy to answer any questions.* |

## 3. Describing charts and trends ⭐
| Movement | Verbs | Nouns | Adjectives / adverbs |
|---|---|---|---|
| ↗ | increase, rise, grow, go up, climb, soar (a lot), peak | an increase, a rise, growth | sharp(ly), steep(ly), dramatic(ally), significant(ly) |
| ↘ | decrease, fall, drop, decline, go down, plunge (a lot) | a decrease, a fall, a drop, a decline | slight(ly), gradual(ly), modest(ly) |
| → | remain stable, level off, stabilise, plateau | a plateau | steady, steadily |
| ↕ | fluctuate | fluctuation | volatile |
| highest / lowest | reach a peak / hit a low | a peak / a low | |

Prepositions with numbers: rose **by** 10% (difference) · rose **to** 500 (final value) · **from** 400 **to** 500 · **at** 500 (level) · a rise **of** 10%.

### Example narration
> *As you can see, revenue **rose steadily** from January to April, **peaking at** 1.2 million dollars in May. It then **dropped sharply by** 18 percent in June, **mainly due to** the website outage, before **levelling off** in the third quarter. **The key takeaway is** that availability has a direct impact on sales, **so we recommend** investing in monitoring.*

## 4. Handling questions
| Situation | Phrase |
|---|---|
| Good question | *That's a great question, thank you.* |
| Clarify | *If I understand correctly, you're asking whether…* |
| Don't know | *I don't have that number with me, but I'll find out and get back to you.* |
| Off-topic | *That's a bit outside the scope of today, but happy to discuss it afterwards.* |
| Check | *Does that answer your question?* |

## 5. Delivery tips
- Speak **slowly**; pause after key numbers.
- Stress the important word: *Revenue grew by **twenty** percent.*
- One message per slide; titles as sentences (*"Churn doubled after the price change"*).
- Practise with a timer and record yourself.
