## 3. Phrases you will hear (and should use)
| Phrase | Meaning |
|---|---|
| *Let's align on next steps.* | Pongámonos de acuerdo en los siguientes pasos. |
| *Can you take the lead on this?* | ¿Puedes encabezar esto? |
| *I don't have the bandwidth this week.* | No tengo tiempo esta semana. |
| *Let's loop in the security team.* | Incluyamos al equipo de seguridad. |
| *What's the ETA?* | ¿Para cuándo estará? (estimated time of arrival) |
| *This is out of scope.* | Esto está fuera del alcance. |
| *Let's set up a quick sync.* | Agendemos una reunión breve. |
| *I'll escalate it if we don't hear back.* | Lo escalaré si no responden. |
| *Please find attached…* | Adjunto encontrarás… |
| *Going forward, …* | De ahora en adelante… |
| *Per our conversation, …* | Según lo conversado… |
| *Any thoughts?* | ¿Comentarios? |
