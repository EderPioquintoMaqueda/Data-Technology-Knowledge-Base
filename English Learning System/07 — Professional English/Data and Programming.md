## 7. Reading code aloud
| Code | Say |
|---|---|
| `df.groupby("region").sum()` | "df dot group by region, dot sum" |
| `x = y + 1` | "x equals y plus one" / "set x to y plus one" |
| `if x > 0:` | "if x is greater than zero" |
| `for row in rows:` | "for each row in rows" |
| `def load(path):` | "define a function load that takes path" |
| `arr[2:5]` | "arr from index two to five" / "arr slice two to five" |
| `SELECT * FROM t WHERE id = 3;` | "select star from t where id equals three" |
| `import pandas as pd` | "import pandas as p-d" |
| `!=` | "not equal to" |
| `**kwargs` | "double-star kwargs" / "keyword arguments" |

## 8. Useful sentences for daily work
| English | Español |
|---|---|
| The script throws an error when the file is empty. | El script lanza un error cuando el archivo está vacío. |
| I'm getting a timeout when I call the API. | Me sale un timeout al llamar a la API. |
| Could you walk me through this function? | ¿Me podrías explicar esta función paso a paso? |
| It works on my machine, but it fails in production. | Funciona en mi computadora pero falla en producción. |
| I've pushed the changes to my branch. | Subí los cambios a mi rama. |
| Can you review my pull request when you have a moment? | ¿Puedes revisar mi PR cuando tengas un momento? |
| The query takes too long; I think we're missing an index. | La consulta tarda demasiado; creo que falta un índice. |
| Let's reproduce the bug first. | Primero reproduzcamos el error. |
| I'll write a test to cover this edge case. | Escribiré una prueba para cubrir este caso límite. |
| The data doesn't add up — the totals don't match. | Los datos no cuadran; los totales no coinciden. |
| Revenue spiked in March and then levelled off. | Los ingresos se dispararon en marzo y luego se estabilizaron. |
