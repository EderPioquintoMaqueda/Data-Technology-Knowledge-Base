# 🧱 Sentence Building — From Simple to Complex Sentences

> Goal: go from *"I work with data."* to *"Although the pipeline had been running for years, we redesigned it last quarter because the data volume, which had tripled, was causing timeouts that nobody could explain."*

## The ladder
| Step | Note | You learn | Level |
|---|---|---|---|
| 1 | [[SB-01 Simple Sentences - Word Order]] | S + V + O + Manner + Place + Time | A1 |
| 2 | [[SB-02 Questions and Negatives]] | do/does/did, auxiliaries, wh- questions | A1–A2 |
| 3 | [[SB-03 Compound Sentences - FANBOYS]] | and, but, or, so, yet… | A2 |
| 4 | [[SB-04 Complex Sentences - Subordinate Clauses]] | because, although, when, if, while… | B1 |

| 6 | [[SB-06 Advanced Structures and Connectors]] | noun clauses, participles, inversion, cleft sentences, linking words | B2–C1 |

## Sentence types
| Type | Structure | Example |
|---|---|---|
| **Simple** | 1 independent clause | *The query is slow.* |
| **Compound** | 2+ independent clauses + coordinator | *The query is slow, **so** we added an index.* |
| **Complex** | independent + dependent clause | ***Because** the table was huge, the query was slow.* |
| **Compound-complex** | 2+ independent + 1+ dependent | ***Although** we added an index, the query was still slow, **so** we partitioned the table.* |

## Daily method (15 minutes)
1. Take one simple sentence about your work.
2. Expand it 5 times: add **when**, **why**, **how**, a **relative clause**, a **contrast**.
3. Say each version aloud; record the last one.
4. Write the final version in your [[Vocabulary Database]] or journal.

### Expansion example
1. *I cleaned the data.*
2. *I cleaned the customer data **yesterday**.*
3. *I cleaned the customer data yesterday **because it had many duplicates**.*
4. *I cleaned the customer data, **which came from three different systems**, yesterday because it had many duplicates.*
5. ***Although it took longer than expected**, I cleaned the customer data, which came from three different systems, yesterday because it had many duplicates.*
6. *Although it took longer than expected, I cleaned the customer data, which came from three different systems, yesterday because it had many duplicates, **so the dashboard now shows accurate numbers**.*
