# SB-01 — Simple Sentences: Word Order

## 1. The golden rule: S + V + O
English word order is **fixed**. Spanish is flexible ("Ayer compré pan" / "Compré pan ayer"), English is not.

| Subject | Verb | Object | Manner | Place | Time |
|---|---|---|---|---|---|
| I | analyse | sales data | carefully | at the office | every Monday. |
| She | presented | the report | clearly | in the meeting | yesterday. |
| We | will deploy | the model | — | to production | next week. |

Memory trick: **S-V-O-M-P-T** → "*Some Very Old Men Play Tennis*".

## 2. The subject is mandatory
| ❌ Spanish-style | ✅ English |
|---|---|
| Is raining. | **It** is raining. |
| Is important to test. | **It** is important to test. |
| Are many errors. | **There are** many errors. |
| Works in IBM. | **He** works **at** IBM. |

### "There is / There are" = hay
- *There **is** a bug in the code.* — Hay un error en el código.
- *There **are** three tables.* — Hay tres tablas.
- *There **was** a problem yesterday.* — Hubo un problema ayer.
- *There **will be** a meeting.* — Habrá una reunión.

## 3. Adjectives go BEFORE the noun
| ❌ | ✅ |
|---|---|
| a database relational | a **relational database** |
| the report final | the **final report** |
| data clean | **clean data** |
Adjectives **never** take plural "s": *two big tables* (not *bigs*).
Several adjectives order: opinion → size → age → shape → colour → origin → material → purpose → **noun**: *a great new open-source Python library*.

## 4. Nouns as adjectives (very common in tech)
The **last** noun is the main one; the others describe it:
- *customer data* = datos de clientes
- *data quality report* = reporte de calidad de datos
- *SQL query performance* = rendimiento de consultas SQL
- *machine learning model training time* = tiempo de entrenamiento del modelo de ML
Read compound nouns **from right to left** to translate them.

## 5. Adverbs of frequency: before the main verb, after "be"
| | Example |
|---|---|
| before main verb | *I **always** check the logs.* |
| after *to be* | *The server **is usually** fast.* |
| after first auxiliary | *I have **never** used Spark.* |
always (100%) · usually · often · sometimes · rarely · never (0%)

## 6. Verb + object: don't separate them
❌ *I like very much Python.* → ✅ *I like Python **very much**.*
❌ *She speaks very well English.* → ✅ *She speaks English **very well**.*

## 7. Building practice — 20 simple sentences for work
| English | Español |
|---|---|
| I work with data every day. | Trabajo con datos todos los días. |
| My team builds dashboards in Power BI. | Mi equipo construye tableros en Power BI. |
| The database stores millions of records. | La base de datos guarda millones de registros. |
| This query returns the top ten customers. | Esta consulta devuelve los diez clientes principales. |
| We clean the data before the analysis. | Limpiamos los datos antes del análisis. |
| The pipeline runs every night at two a.m. | El pipeline corre cada noche a las 2 a.m. |
| She writes Python scripts quickly. | Ella escribe scripts de Python rápido. |
| There is a missing value in this column. | Hay un valor faltante en esta columna. |
| It is important to document the code. | Es importante documentar el código. |
| The new model is more accurate. | El modelo nuevo es más preciso. |
| I usually test my code locally. | Normalmente pruebo mi código localmente. |
| The server is often slow on Mondays. | El servidor suele estar lento los lunes. |
| We deployed the API last week. | Desplegamos la API la semana pasada. |
| They need the report by Friday. | Necesitan el reporte para el viernes. |
| I will learn SQL window functions this month. | Aprenderé funciones de ventana de SQL este mes. |
| The customer table has twelve columns. | La tabla de clientes tiene doce columnas. |
| Our company uses PostgreSQL. | Nuestra empresa usa PostgreSQL. |
| The data quality is very good. | La calidad de los datos es muy buena. |
| He explained the results clearly. | Él explicó los resultados claramente. |
| I have never used Airflow. | Nunca he usado Airflow. |

## 🧪 Exercises
Put the words in order:
1. every / the logs / morning / checks / she
2. data / at work / I / yesterday / cleaned / the
3. is / there / a / in / the / bug / code
4. a / built / dashboard / new / we / sales
<details><summary>Answers</summary>

1. She checks the logs every morning. 2. I cleaned the data at work yesterday. 3. There is a bug in the code. 4. We built a new sales dashboard.
</details>
