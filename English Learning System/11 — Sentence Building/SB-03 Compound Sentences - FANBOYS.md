# SB-03 — Compound Sentences (Coordinating Conjunctions)

A **compound sentence** joins two complete sentences (independent clauses) with a **coordinating conjunction**. Memorise **FANBOYS**:

| Conj. | Meaning | Function | Example | Español |
|---|---|---|---|---|
| **F**or | porque (formal) | reason | We stopped the job, **for** it was corrupting data. | …pues estaba corrompiendo datos. |
| **A**nd | y | addition | I wrote the query, **and** Ana reviewed it. | Escribí la consulta y Ana la revisó. |
| **N**or | ni | negative addition | He didn't call, **nor** did he send an email. | No llamó, ni envió un correo. |
| **B**ut | pero | contrast | The model is accurate, **but** it is slow. | El modelo es preciso pero lento. |
| **O**r | o | alternative | We can use Polars, **or** we can use DuckDB. | Podemos usar Polars o DuckDB. |
| **Y**et | sin embargo / aun así | surprising contrast | The test passed, **yet** the bug is still there. | La prueba pasó; aun así el error sigue. |
| **S**o | así que / por lo que | result | The table was huge, **so** we partitioned it. | La tabla era enorme, así que la particionamos. |

### Punctuation
- Two complete clauses → **comma before** the conjunction: *It failed, so we retried.*
- Same subject, second subject omitted → no comma: *We cleaned the data and loaded it.*
- ⚠️ "Nor" causes inversion: *nor **did he** send*.

## Semicolon + transition (more formal)
*The query was slow**; therefore,** we added an index.*
*The API is fast**; however,** it is expensive.*
| Transition | Meaning |
|---|---|
| however | sin embargo |
| therefore / thus | por lo tanto |
| moreover / furthermore | además |
| otherwise | de lo contrario |
| meanwhile | mientras tanto |
| instead | en cambio |

## Correlative pairs
| Pair | Example |
|---|---|
| both … and | **Both** Python **and** SQL are required. |
| either … or | **Either** you restart the server **or** you clear the cache. |
| neither … nor | **Neither** the logs **nor** the metrics show an error. |
| not only … but also | It is **not only** faster **but also** cheaper. |

## Ladder practice
1. *The dashboard is useful.*
2. *The dashboard is useful, **but** it loads slowly.*
3. *The dashboard is useful, but it loads slowly, **so** we will optimise the queries.*
4. *The dashboard is useful, but it loads slowly; **therefore**, we will optimise the queries **and** cache the results.*
5. ***Not only** is the dashboard useful, **but** it **also** drives weekly decisions; **however**, it loads slowly, so we will optimise the queries.*

## 🧪 Exercises — join with the best conjunction
1. I wanted to join the call. My internet was down.
2. We can deploy today. We can wait for the tests.
3. The data was incomplete. The results were wrong.
4. He didn't update the documentation. He didn't tell the team.
<details><summary>Answers</summary>

1. …, but my internet was down. 2. …, or we can wait for the tests. 3. …, so the results were wrong. 4. He didn't update the documentation, nor did he tell the team.
</details>
