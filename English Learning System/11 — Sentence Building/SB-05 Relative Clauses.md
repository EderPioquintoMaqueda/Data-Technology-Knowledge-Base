# SB-05 — Relative Clauses

Relative clauses add information about a noun — they let you **combine two sentences into one**.
*The engineer fixed the bug. **She** joined last month.* → *The engineer **who joined last month** fixed the bug.*

## 1. Relative pronouns
| Pronoun | For | Example | Español |
|---|---|---|---|
| **who** | people | The analyst **who** built the model left. | que / quien |
| **which** | things | The table **which** stores orders is huge. | que / el cual |
| **that** | people or things (defining only) | The script **that** failed is old. | que |
| **whose** | possession | The client **whose** data we lost called. | cuyo/a |
| **where** | places | The server **where** the DB runs is in Virginia. | donde |
| **when** | times | 2020 was the year **when** we moved to the cloud. | cuando |
| **why** | reasons | That's the reason **why** it failed. | por la que |
| **whom** | people, object (formal) | The manager **to whom** I reported… | a quien |

## 2. Defining vs non-defining ⚠️
| | Defining (essential) | Non-defining (extra info) |
|---|---|---|
| Purpose | identifies **which one** | adds a comment |
| Commas | **no** commas | **commas** |
| "that" allowed? | ✅ | ❌ (use who/which) |
| Example | *The tables **that have no index** are slow.* (only some tables) | *The tables, **which have no index**, are slow.* (all the tables) |

## 3. Omitting the pronoun
In **defining** clauses you can omit who/which/that when it is the **object**:
- *The query (**that**) **you wrote** is fast.* ✅ omit
- *The query **that returns** duplicates is wrong.* ❌ can't omit (it's the subject)

## 4. Prepositions in relative clauses
- Informal: *The project (that) I work **on**.*
- Formal: *The project **on which** I work.*
- *The team **with whom** we collaborate…* / *the database **from which** we extract data*

## 5. "Which" referring to a whole idea
*The job failed three times, **which** delayed the whole report.* (= *y eso retrasó…*)

## 6. Reduced relative clauses (advanced, very common in technical writing)
| Full | Reduced |
|---|---|
| Files **that are stored** in S3 | Files **stored** in S3 |
| Users **who are waiting** for access | Users **waiting** for access |
| The model **that was trained** last week | The model **trained** last week |
| Data **that comes from** sensors | Data **coming from** sensors |

## 7. Ladder practice
1. *The pipeline is critical.*
2. *The pipeline **that loads sales data** is critical.*
3. *The pipeline that loads sales data, **which runs every night**, is critical.*
4. *The pipeline that loads sales data, which runs every night **on a server where other jobs also run**, is critical.*
5. *The pipeline that loads sales data, which runs every night on a server where other jobs also run, is critical **for the finance team, whose reports depend on it**.*

## 🧪 Exercises
Join with a relative clause:
1. I met a developer. He contributes to pandas.
2. This is the dashboard. The CEO checks it every morning.
3. The vendor sent the file. Its format was wrong.
4. We use PostgreSQL. It is open source. (non-defining)
<details><summary>Answers</summary>

1. I met a developer who contributes to pandas. 2. This is the dashboard (that) the CEO checks every morning. 3. The vendor whose file format was wrong… / The vendor sent the file, whose format was wrong. 4. We use PostgreSQL, which is open source.
</details>
