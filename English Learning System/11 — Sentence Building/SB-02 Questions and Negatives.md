# SB-02 — Questions and Negatives

## 1. The auxiliary is the key
English questions and negatives need an **auxiliary verb**. If the sentence has one (*be, have, can, will, should…*), use it. If not, use **do / does / did**.

| Tense | Affirmative | Negative | Question |
|---|---|---|---|
| to be | The data **is** clean. | The data **isn't** clean. | **Is** the data clean? |
| Present simple | She **works** remotely. | She **doesn't work** remotely. | **Does** she **work** remotely? |
| Past simple | They **fixed** the bug. | They **didn't fix** the bug. | **Did** they **fix** the bug? |
| Present continuous | We **are testing**. | We **aren't testing**. | **Are** we **testing**? |
| Present perfect | You **have deployed** it. | You **haven't deployed** it. | **Have** you **deployed** it? |
| Future | It **will run** tonight. | It **won't run** tonight. | **Will** it **run** tonight? |
| Modal | I **can** access the DB. | I **can't** access the DB. | **Can** I access the DB? |

⚠️ After *do/does/did* the verb goes back to its **base form**: *Does she work*~~s~~? · *Did they fix*~~ed~~?

## 2. Question structure: QASI
**Q**uestion word + **A**uxiliary + **S**ubject + **I**nfinitive (main verb) + rest
| Q | A | S | I | rest |
|---|---|---|---|---|
| What | does | this query | return? | |
| Why | did | the pipeline | fail | last night? |
| How long | will | the migration | take? | |
| Where | are | the logs | stored? | |
| Which table | should | we | use? | |

### Question words
| Word | Meaning | Example |
|---|---|---|
| What | qué | What is the error? |
| Which | cuál (de opciones) | Which version do you use? |
| Who | quién | Who owns this dataset? |
| Whose | de quién | Whose laptop is this? |
| When | cuándo | When is the deadline? |
| Where | dónde | Where is the file? |
| Why | por qué | Why is it slow? |
| How | cómo | How does it work? |
| How much / many | cuánto/s | How many rows are there? / How much memory do we need? |
| How long | cuánto tiempo | How long does it take? |
| How often | con qué frecuencia | How often does it run? |

### Subject questions (no do/does!)
When the question word **is** the subject: *Who **wrote** this code?* (not *Who did write*). *What **happened**?* *Which job **failed**?*

## 3. Polite and indirect questions (professional English)
| Direct | Indirect / polite |
|---|---|
| Where is the documentation? | Could you tell me **where the documentation is**? |
| Why did it fail? | Do you know **why it failed**? |
| What time is the meeting? | I was wondering **what time the meeting is**. |
⚠️ In indirect questions, use **normal word order** (no inversion, no do/does).

## 4. Question tags (confirmation)
- *The report is ready, **isn't it**?*
- *You tested it, **didn't you**?*
- *We can't delete that table, **can we**?*

## 5. Negatives: more than "not"
| Structure | Example | Español |
|---|---|---|
| never | I **never** skip tests. | Nunca me salto pruebas. |
| no + noun | There are **no** errors. | No hay errores. |
| not any | There **aren't any** errors. | No hay ningún error. |
| nothing / nobody / nowhere | **Nothing** changed. | Nada cambió. |
| no longer | We **no longer** use Excel for this. | Ya no usamos Excel para esto. |
| not yet | It **isn't** ready **yet**. | Todavía no está listo. |
⚠️ No double negatives: ❌ *I don't know nothing* → ✅ *I don't know anything*.

## 🧪 Exercises
Make questions for the **bold** part:
1. The job runs **every hour**. 2. **Carlos** created the table. 3. The file has **2,000** rows. 4. We use Docker **because it is reproducible**.
Make negative: 5. She uploaded the file. 6. There are some nulls.
<details><summary>Answers</summary>

1. How often does the job run? 2. Who created the table? 3. How many rows does the file have? 4. Why do you use Docker? 5. She didn't upload the file. 6. There aren't any nulls. / There are no nulls.
</details>
