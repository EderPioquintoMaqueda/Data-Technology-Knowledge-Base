# SB-06 — Advanced Structures and Connectors

## 1. Noun clauses (a clause used as a noun)
| Starter | Example | Español |
|---|---|---|
| that | ***That** the data was wrong* surprised everyone. / I think **(that)** we need more tests. | Que los datos estuvieran mal… |
| what | ***What** we need* is better monitoring. | Lo que necesitamos… |
| whether / if | I don't know **whether** the job finished. | si |
| wh- word | Can you explain **how** this works? | cómo |
| the fact that | ***The fact that** nobody noticed* is worrying. | El hecho de que… |

## 2. Participle clauses (compress two actions)
| Type | Example |
|---|---|
| Present participle (-ing) — same time / cause | ***Running** on a small server*, the job often times out. |
| Past participle — passive meaning | ***Written** in Rust*, Polars is extremely fast. |
| Perfect participle — earlier action | ***Having tested** the code*, we merged the PR. |
| With subject (absolute) | ***The tests having passed***, we deployed. |
⚠️ The subject of the participle must be the subject of the main clause: ❌ *Running the query, the screen froze.* (the screen didn't run it) → ✅ *While I was running the query, the screen froze.*

## 3. Cleft sentences (emphasis)
- ***It was** the index **that** fixed the problem.* (not the hardware)
- ***What** fixed the problem **was** the index.*
- ***All** we need **is** a clean dataset.*
- ***The reason why** it failed **is that** the token expired.*

## 4. Inversion (formal, presentations & writing)
| Normal | Inverted |
|---|---|
| We had **never** seen such a spike. | **Never had we** seen such a spike. |
| The system **not only** failed but also lost data. | **Not only did** the system fail, **but** it also lost data. |
| We **only** understood the cause later. | **Only later did we** understand the cause. |
| As soon as we deployed, errors appeared. | **No sooner had we** deployed **than** errors appeared. |
| If you should need help, call me. | **Should you** need help, call me. |
| If we had known, we would have waited. | **Had we known**, we would have waited. |

## 5. Passive voice for objective writing
*The data **was collected** from 12 sources and **has been validated** by the QA team.* → see [[Passive Voice]].

## 6. Linking words — master table
| Function | Formal (writing) | Neutral | Informal (speaking) |
|---|---|---|---|
| Add | furthermore, moreover, in addition | also, as well as | plus, on top of that |
| Contrast | nevertheless, nonetheless, conversely | however, although, whereas | but, still, though (end) |
| Cause | due to, owing to, as a result of | because (of), since | 'cause |
| Result | consequently, hence, thus | therefore, as a result | so |
| Example | for instance, namely | for example, such as | like |
| Sequence | subsequently, finally | first, then, after that | then, next |
| Emphasis | in particular, notably | especially, indeed | really |
| Concession | admittedly, granted | even so, despite this | anyway |
| Conclusion | in conclusion, to sum up | overall, in short | basically |
| Clarify | that is to say, i.e. | in other words | I mean |

## 7. A full compound-complex paragraph (deconstructed)
> ***Although** the legacy pipeline **had been running** reliably for years, we redesigned it last quarter **because** the data volume, **which had tripled since 2024**, was causing timeouts **that** nobody could reproduce locally. **Having analysed** the logs, we discovered **that** a single unindexed join was responsible; **consequently**, we rewrote it in dbt, added tests, and scheduled it in Airflow. **Not only did** runtime drop **from** four hours **to** twenty minutes, **but** data-quality incidents **also** fell by 80 percent.*

| Piece | Structure |
|---|---|
| Although … years | concessive subordinate clause + past perfect continuous |
| because … locally | reason clause containing two relative clauses |
| Having analysed the logs | perfect participle clause |
| that a single … responsible | noun clause |
| ; consequently, | formal result connector |
| Not only did … but … also | inversion for emphasis |

## 🧪 Exercises
1. Rewrite with inversion: *We rarely see such clean data.*
2. Make a cleft sentence emphasising "the cache": *The cache caused the error.*
3. Combine with a participle: *I reviewed the PR. I noticed a security issue.*
4. Write a 4-sentence paragraph about a project you did, using: although, which, consequently, not only… but also.
