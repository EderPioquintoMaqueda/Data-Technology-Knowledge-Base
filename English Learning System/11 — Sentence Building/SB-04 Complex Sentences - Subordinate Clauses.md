# SB-04 — Complex Sentences (Subordinate Clauses)

A **complex sentence** = main clause + **dependent clause** introduced by a **subordinating conjunction**. The dependent clause cannot stand alone: *~~Because it was slow.~~*

## 1. Subordinating conjunctions by meaning
| Meaning | Conjunctions | Example | Español |
|---|---|---|---|
| **Reason** | because, since, as | We added an index **because** the query was slow. | …porque la consulta era lenta. |
| **Contrast** | although, even though, though, while, whereas | **Although** the model is simple, it works well. | Aunque el modelo es simple… |
| **Time** | when, while, before, after, until, as soon as, once, since | **Once** the data arrives, the job starts. | Una vez que llegan los datos… |
| **Condition** | if, unless, as long as, provided that, in case | **Unless** you commit, the changes are lost. | A menos que hagas commit… |
| **Purpose** | so that, in order to (+verb) | We log errors **so that** we can debug later. | …para que podamos depurar. |
| **Result** | so … that, such … that | The file was **so** big **that** Excel crashed. | Tan grande que… |
| **Comparison** | as if, as though | It behaves **as if** the cache were empty. | Como si… |

## 2. Position and punctuation
- Dependent clause **first** → comma: ***When** the job fails, we receive an alert.*
- Dependent clause **second** → usually no comma: *We receive an alert **when** the job fails.*

## 3. Tense rules that Spanish speakers miss
| Rule | ❌ | ✅ |
|---|---|---|
| Future time after *when/as soon as/until/before/if* → **present** | When the data **will arrive**, … | When the data **arrives**, … |
| *Since* + point in time → present perfect in main clause | I work here since 2024. | I **have worked** here **since** 2024. |
| *Unless* already negative | Unless you **don't** test… | Unless you test… |
| *Although* ≠ *but* together | Although it's slow, but it works. | Although it's slow, it works. |

## 4. Reduced forms (more natural, B2)
| Full | Reduced |
|---|---|
| **After we finished** the migration, we celebrated. | **After finishing** the migration, we celebrated. |
| **While I was reviewing** the code, I found a bug. | **While reviewing** the code, I found a bug. |
| We use Docker **so that we can** reproduce the environment. | We use Docker **to** reproduce the environment. |
| **Because of** the outage… (+ noun) | vs **because** the server was down (+ clause) |
| **Despite** the delay / **Despite being** late | vs **although** it was late |

## 5. Ladder practice
1. *The migration failed.*
2. *The migration failed **because** the disk was full.*
3. ***Although** we had tested it, the migration failed because the disk was full.*
4. *Although we had tested it **twice**, the migration failed because the disk was full **when** the nightly backup started.*
5. *Although we had tested it twice, the migration failed because the disk was full when the nightly backup started, **so that** now we monitor disk space **before** any deployment.* → better: *…, so now we monitor disk space before every deployment.*

## 🧪 Exercises
Combine:
1. The report was late. The data arrived late. (because)
2. The model is accurate. Nobody uses it. (although)
3. You finish the tests. Tell me. (as soon as)
4. We won't deploy. The manager approves. (unless)
<details><summary>Answers</summary>

1. The report was late because the data arrived late. 2. Although the model is accurate, nobody uses it. 3. Tell me as soon as you finish the tests. 4. We won't deploy unless the manager approves.
</details>
