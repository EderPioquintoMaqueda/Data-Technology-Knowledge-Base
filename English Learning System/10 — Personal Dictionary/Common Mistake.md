# 🚫 Common Mistakes of Spanish Speakers | Errores comunes

> Add your own mistakes at the bottom every time a teacher, tool or colleague corrects you.

## 1. Grammar
| ❌ Mistake | ✅ Correct | Why |
|---|---|---|
| She work in IT. | She **works** in IT. | 3rd person -s |
| I have 30 years. | I **am** 30 (years old). | age uses *be* |
| I am agree. | I agree. | *agree* is a verb |
| People is happy. | People **are** happy. | *people* is plural |
| The informations are… | The information **is**… | uncountable |
| I have many works. | I have a lot of **work**. | *work* uncountable |
| Is important to test. | **It** is important to test. | subject required |
| Are many errors. | **There are** many errors. | *hay* = there is/are |
| I didn't went. | I didn't **go**. | base verb after *did* |
| Do you can help me? | **Can** you help me? | modals don't use *do* |
| I live here since 2020. | I **have lived** here since 2020. | present perfect with *since/for* |
| Yesterday I have worked a lot. | Yesterday I **worked** a lot. | finished time → past simple |
| When I will finish, I'll call. | When I **finish**, I'll call. | present after *when* (future) |
| If I would know, I would tell you. | If I **knew**, I would tell you. | no *would* in the if-clause |
| He said me that… | He **told** me that… / He said **to** me… | say vs tell |
| Explain me. | Explain **to me**. | explain + to |
| I want that you check it. | I want **you to check** it. | want + object + to |
| I'm used to work late. | I'm used to **working** late. | *used to* (be used to) + -ing |
| Look forward to see you. | Look forward to **seeing** you. | *to* is a preposition |
| Make a question. | **Ask** a question. | collocation |
| The most big table. | The **biggest** table. | short adjectives -est |
| More easy | **Easier** | -y → -ier |
| Very much people | **A lot of** people / **Many** people | |
| Less errors | **Fewer** errors | countable |
| I have a doubt. | I have a **question**. | *doubt* = skepticism |
| Since two hours. | **For** two hours. | for = duration |
| In the next week | **Next** week | no preposition |
| The last week (meaning past) | **Last** week | no article |
| I go to home. | I go home. | *home* no *to* |
| Assist to the meeting | **Attend** the meeting | false friend |

## 2. Pronunciation
| ❌ | ✅ |
|---|---|
| "es-tart", "es-QL" | /stɑːrt/, /es.kjuːˈel/ — no initial "e" |
| "work-ed" (2 syllables) | /wɝːkt/ — 1 syllable |
| "beach" = "bitch" | long /iː/ |
| b = v | /v/ teeth on lip |
| "tink", "sink" for *think* | /θ/ tongue between teeth |
| "jello" for *yellow* | /j/ semivowel |
| silent final consonants: "tes" | test, /test/ |
| stress on wrong syllable: "de-ve-LOP" | de-**VEL**-op |
| "pi-ton" | **PÁI**-zan (Python) |

## 4. Writing
| ❌ | ✅ |
|---|---|
| Lowercase days/months: monday, november | **M**onday, **N**ovember |
| Lowercase nationalities/languages: english, mexican | **E**nglish, **M**exican |
| ¿Opening question mark? | No opening ¿ or ¡ |
| 1.250,50 | 1,250.50 |
| Very long sentences with many commas | Shorter sentences; use connectors |
| Dear Sir: | Dear Sir, (comma) / Hi Ana, |
