# 📝 Exams & Level Checks

## 1. CEFR levels (Marco Común Europeo)
| Level | Can do | Typical for data jobs |
|---|---|---|
| A1–A2 | basic phrases, simple routines | read code & errors |
| **B1** | handle work situations, describe experiences | read docs, write simple emails |
| **B2** | discuss technical topics fluently, understand meetings | ✅ minimum for most international roles |
| C1 | flexible, precise, nuanced | presentations, leadership, client-facing |
| C2 | near-native | — |

## 2. Free placement tests
- **EF SET** (efset.org) — free, 50 min, CEFR score.
- **Cambridge English** "Test your English" — quick check.
- **British Council** online level test.
Take one **now** and again every 3 months; record results below.

## 3. Official certifications (for CV / visas)
| Exam | Format | When useful |
|---|---|---|
| TOEFL iBT | academic, online/centre | US universities |
| IELTS (Academic / General) | academic or work | UK, Canada, Australia |
| Cambridge B2 First / C1 Advanced | lifelong certificate | Europe, employers |
| Duolingo English Test | online, cheap | many universities |
| TOEIC | business English | companies in LatAm/Asia |
Check current prices and formats on the official sites before registering.

## 4. Self-made monthly exam (60 min)
| Section | Task | Points |
|---|---|---|
| Grammar | 20 questions from [[Exercises]] (new ones) | 20 |
| Vocabulary | translate 20 words from [[Vocabulary Database]] both ways | 20 |
| Listening | 5-min tech podcast clip → write a 5-sentence summary | 20 |
| Writing | 150-word email reporting an incident ([[Writing Professional Emails and Messages]]) | 20 |
| Speaking | 2-min recording: explain a project with numbers | 20 |
| **Total** | | **100** |

Score guide: 85+ → move to next level material · 70–84 → review weak sections · <70 → repeat month.
