# 📅 Weekly Evaluation Template

> Copy the template below every Sunday (or use Obsidian's **Templates** core plugin). 15 minutes of honest review.

## Template
```markdown
### Week __ (YYYY-MM-DD → YYYY-MM-DD)

**Study time:** __ h English · __ h Python · __ h SQL

**English**
- New words learned (box ≥ 2): __ / 50
- Grammar topic: [[ ]] — confidence 1–5: __
- Sentence-building level reached: SB-__
- Speaking recordings: __ / 5
- Listening (minutes): __
- Mistake of the week: "___" → "___"

**Tech (in English!)**
- Python notes completed: [[ ]]
- SQL exercises solved: __ / 10 (✅ __ 🟡 __ ❌ __)
- One thing I can now explain in English: ___

**Reflection**
- What went well:
- What was hard:
- Next week's focus:
```

## Scoring rubric (speaking/writing)
| Criterion | 1 | 3 | 5 |
|---|---|---|---|
| Grammar | many basic errors | some errors, meaning clear | few errors, complex sentences |
| Vocabulary | basic, repetitive | adequate, some tech terms | precise, varied, collocations |
| Fluency | long pauses | some pauses | natural flow |
| Pronunciation | hard to understand | understandable, accent | clear, good stress |
| Structure | no connectors | basic connectors | clear structure, signposting |
