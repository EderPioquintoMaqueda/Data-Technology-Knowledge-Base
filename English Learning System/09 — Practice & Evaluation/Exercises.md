# ✍️ Mixed English Exercises (with answers)

Do one block per day. Write answers in a notebook or below each block, then check.

## Block 1 — Tenses (A2–B1)
Complete with the correct form:
1. She usually ___ (start) work at 9.
2. Look! The job ___ (run) right now.
3. I ___ (finish) the report yesterday.
4. We ___ (use) PostgreSQL since 2023.
5. When I arrived, the meeting ___ (already / start).
6. By next Friday, we ___ (migrate) all the tables.
7. I ___ (work) on this bug for three hours — I'm exhausted!
8. If it ___ (rain) tomorrow, we'll stay home.
9. If I ___ (be) you, I would learn SQL first.
10. If we ___ (test) it, the bug wouldn't have reached production.
<details><summary>Answers</summary>

1 starts · 2 is running · 3 finished · 4 have used / have been using · 5 had already started · 6 will have migrated · 7 have been working · 8 rains · 9 were · 10 had tested
</details>

## Block 2 — Questions (A2)
Write the question for the underlined/bold part:
1. The dashboard refreshes **every hour**.
2. **Ana** fixed the bug.
3. The table has **3 million** rows.
4. They chose Polars **because it is faster**.
5. The file is **in the shared folder**.
<details><summary>Answers</summary>

1 How often does the dashboard refresh? · 2 Who fixed the bug? · 3 How many rows does the table have? · 4 Why did they choose Polars? · 5 Where is the file?
</details>

## Block 3 — Prepositions (A2–B1)
1. The meeting is ___ Tuesday ___ 3 p.m.
2. I was born ___ 1995 ___ Puebla.
3. The data is ___ the second sheet.
4. She's good ___ statistics and interested ___ AI.
5. It depends ___ the size of the data.
6. Please send it ___ Friday at the latest.
<details><summary>Answers</summary>1 on, at · 2 in, in · 3 on · 4 at, in · 5 on · 6 by</details>

## Block 4 — Passive and reported speech (B1–B2)
Passive:
1. They store the backups in S3.
2. Someone has changed the password.
3. The team will release the API next week.
Reported speech:
4. "I'm testing the new model," she said.
5. "Did you merge the branch?" he asked me.
6. "Don't delete the logs," the manager told us.
<details><summary>Answers</summary>

1 The backups are stored in S3. · 2 The password has been changed. · 3 The API will be released next week. · 4 She said she was testing the new model. · 5 He asked me if I had merged the branch. · 6 The manager told us not to delete the logs.
</details>

## Block 5 — Sentence combining (B1–B2)
Combine into one sentence using the word in brackets:
1. The query was slow. It scanned the whole table. (because)
2. The model is accurate. It is too expensive to run. (although)
3. I met an engineer. She works on Spark. (who)
4. We tested the code. We deployed it. (after + -ing)
5. The data was wrong. Nobody noticed it. (the fact that)
<details><summary>Answers</summary>

1 The query was slow because it scanned the whole table. · 2 Although the model is accurate, it is too expensive to run. · 3 I met an engineer who works on Spark. · 4 After testing the code, we deployed it. · 5 The fact that the data was wrong went unnoticed. / Nobody noticed the fact that the data was wrong.
</details>

## Block 6 — Numbers (A2)
Write in words: 1) 17 vs 70 2) 3,450 3) $12.99 4) 0.05 5) 1/4 6) 2026-03-04 (US style)
<details><summary>Answers</summary>

1 seventeen / seventy · 2 three thousand four hundred (and) fifty · 3 twelve ninety-nine / twelve dollars and ninety-nine cents · 4 zero point zero five · 5 a quarter / one fourth · 6 March fourth, twenty twenty-six
</details>

## Block 7 — False friends & collocations (B1)
1. ___, I don't work there anymore. (Actually / Currently)
2. I ___ a mistake in the query. (did / made)
3. Did you ___ the conference? (assist / attend)
4. Let's ___ a break. (do / take)
5. I didn't ___ the file was empty. (realize / notice — both OK?)
<details><summary>Answers</summary>1 Actually · 2 made · 3 attend · 4 take · 5 both "realize" and "notice" work</details>

## Block 8 — Translation (B1–B2)
Translate into natural English:
1. Hace dos semanas que trabajo en este proyecto.
2. Si hubiera sabido que la tabla era tan grande, habría usado Polars.
3. El reporte, que se genera cada lunes, tiene varios errores.
4. No sólo es más rápido, sino también más barato.
5. Me dijeron que lo terminara para el viernes.
<details><summary>Answers</summary>

1 I've been working on this project for two weeks. · 2 If I had known the table was so big, I would have used Polars. · 3 The report, which is generated every Monday, has several errors. · 4 It's not only faster but also cheaper. / Not only is it faster, but it's also cheaper. · 5 They told me to finish it by Friday.
</details>
