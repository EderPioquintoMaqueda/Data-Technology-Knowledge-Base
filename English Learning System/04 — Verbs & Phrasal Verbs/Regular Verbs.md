# ✅ Regular Verbs | Verbos regulares

Regular verbs form the past and the participle with **-ed**: *work → worked → worked*. The challenge for Spanish speakers is the **pronunciation** of -ed.

## 1. The three sounds of -ED ⭐
| Sound | When (last SOUND of the verb) | Examples | Say it |
|---|---|---|---|
| **/t/** | voiceless sounds: p, k, f, s, sh, ch, x, th | worked, stopped, fixed, pushed, watched, asked | workt, stopt, fikst |
| **/d/** | voiced sounds & vowels: b, g, v, z, l, m, n, r, all vowels | called, used, planned, saved, played, stored | kold, iuzd, pland |
| **/ɪd/** (extra syllable) | only after **t** or **d** | wanted, needed, started, updated, tested, added, deleted | **UAN**-tid, **NI**-did, ap-**DÉI**-tid |

⚠️ Never add an extra syllable unless the verb ends in /t/ or /d/: *worked* = 1 syllable "workt", **not** "work-ed".
⚠️ *Loaded* ends in **d** → /ɪd/: "**LOU**-did".

## 2. Spelling rules
| Rule | Example |
|---|---|
| most verbs: + ed | work → worked, load → loaded |
| ending in -e: + d | use → used, save → saved, merge → merged |
| consonant + y → ied | try → tried, copy → copied, apply → applied, query → queried |
| vowel + y → + ed | play → played, deploy → deployed |
| short stressed CVC → double consonant | stop → stopped, plan → planned, commit → committed, drop → dropped |
| unstressed final syllable → no double (US) | open → opened, visit → visited, cancel → canceled (UK: cancelled) |
