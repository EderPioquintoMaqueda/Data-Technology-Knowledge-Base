# 🧩 Phrasal Verbs | Verbos frasales

A **phrasal verb** = verb + particle (*up, out, off, on, in, down, back, over…*). The meaning often changes completely: *look* (mirar) → *look up* (buscar en un diccionario) → *look after* (cuidar).

## Grammar in 3 rules
1. **Separable** (with object): *set up the server* = *set the server up*. With a **pronoun**, you MUST separate: *set **it** up* ✅ · *set up it* ❌.
2. **Inseparable**: *look after the kids* / *look after them* (never *look them after*).
3. **Intransitive** (no object): *The server **went down**.*

| Phrasal verb | Español | Example |

| go over | repasar | Let's **go over** the results. |
| move on | pasar a otro tema | Let's **move on** to the next item. |
| put off | posponer | They **put off** the meeting. |
| call off | cancelar | The demo was **called off**. |
| catch up (with) | ponerse al día | Let's **catch up** tomorrow. |
| fill (sb) in | poner al tanto | Can you **fill me in** on the project? |
| get back to | responder más tarde | I'll **get back to you** by Friday. |
| reach out (to) | contactar | Feel free to **reach out** if you need help. |
