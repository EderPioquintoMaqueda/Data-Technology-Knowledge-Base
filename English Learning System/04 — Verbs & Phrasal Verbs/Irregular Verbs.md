# 🔁 Irregular Verbs | Verbos irregulares

Learn them **by pattern groups** (much easier than alphabetical). Say the three forms aloud as a rhythm: *"write – wrote – written"*.
Columns: **Base** (infinitivo) · **Past simple** (pasado) · **Past participle** (participio, for *have + PP* and the passive).

## Tech-relevant irregular verbs ⭐
| Verb | Example |
|---|---|
| **build – built – built** | We **built** a new pipeline. |
| **run – ran – run** | The job **ran** for 3 hours. / It has **run** successfully. |
| **write – wrote – written** | I **wrote** the query. / It's **written** in Rust. |
| **send – sent – sent** | The API **sent** a 500 error. |
| **set – set – set** | I **set** the timeout to 10 seconds. |
| **find – found – found** | We **found** the root cause. |
| **break – broke – broken** | The update **broke** the build. / The link is **broken**. |
| **lose – lost – lost** | We **lost** the connection. |
| **bring – brought – brought** | Indexes **brought** the time down. |
| **choose – chose – chosen** | We **chose** PostgreSQL. |
| **spend – spent – spent** | I **spent** two days debugging. |
| **lead – led – led** | She **led** the migration project. |
| **feed – fed – fed** | Data is **fed** into the model. |
| **shut down – shut down** | The server **shut down** unexpectedly. |
| **take – took – taken** | The backup **took** 40 minutes. |
