# 🎧 Pronunciation Drills for Spanish Speakers

> 10 minutes a day. Read each pair aloud, record yourself, compare with YouGlish/Cambridge audio. Key: [[How to Read Pronunciation]] · Theory: [[English Pronunciation]]

## 1. Minimal pairs (words that differ in ONE sound)
### /iː/ (long) vs /ɪ/ (short)
| /iː/ | /ɪ/ |
|---|---|
| sheet | shit ⚠️ |
| beach | bitch ⚠️ |
| leave | live |
| feel | fill |
| seat | sit |
| team | Tim |
| heat | hit |
| read | rid |
Sentence: *Please **leave** the file; don't **live** in the past.*

### /æ/ vs /ʌ/ vs /ɑː/
| /æ/ (cat) | /ʌ/ (cup) | /ɑː/ (car) |
|---|---|---|
| cat | cut | cart |
| hat | hut | heart |
| bag | bug | — |
| ran | run | — |
| match | much | — |
| stack | stuck | stock |
Sentence: *The **bug** is in the **bag**; we're **stuck** with the **stack**.*

### /b/ vs /v/
| /b/ | /v/ |
|---|---|
| best | vest |
| berry | very |
| ban | van |
| boat | vote |
| bet | vet |
Sentence: *The **very best** **value** is **visible** in the **base** **version**.*

### /s/ vs /z/ vs /ʃ/
| /s/ | /z/ | /ʃ/ |
|---|---|---|
| sip | zip | ship |
| price | prize | — |
| sue | zoo | shoe |
| sell | — | shell |
| seat | — | sheet |

### /θ/ (think) vs /t/ vs /s/ ; /ð/ (this) vs /d/
| /θ/ | /t/ / /s/ |
|---|---|
| think | tink / sink |
| thank | tank |
| three | tree |
| thought | taught |
| path | pat / pass |
| /ð/ | /d/ |
| they | day |
| then | den |
| though | dough |
| breathe | breed |
Sentence: *I **think** **these three** **things** are **the** **thirty-third** **thread**.*

### /dʒ/ vs /j/ vs /tʃ/
| /dʒ/ (job) | /j/ (yes) | /tʃ/ (chip) |
|---|---|---|
| jet | yet | — |
| jam | yam | — |
| joke | yolk | choke |
| Jell-O | yellow | — |
| — | — | cheap / jeep |

### Final consonants (don't drop them!)
*test – tests – tested* · *ask – asks – asked* /æskt/ · *script – scripts* · *month – months* /mʌnθs/ · *world* /wɝːld/ · *first* · *text* /tekst/ · *exact*.

### No "e" before s + consonant
*SQL* (not *esql*) · *start* · *stack* · *script* · *schema* · *Spain* · *student* · *special* · *strong*.
Drill: say *"the start"*, *"my script"*, *"a strong schema"* — link the vowel before to the s.

## 2. Word stress drills
| Pattern | Words |
|---|---|
| **O**o | **DA**-ta, **QUE**-ry, **SER**-ver, **CLUS**-ter, **PRO**-cess |
| o**O** | de-**PLOY**, re-**QUEST**, con-**FIG**, ex-**PORT** (verb) |
| o**O**o | de-**VEL**-op, com-**PU**-ter, ex-**CEP**-tion (but: **AL**-go-rithm is **O**oo) |
| oo**O**o | in-for-**MA**-tion, op-ti-mi-**ZA**-tion, ap-pli-**CA**-tion |
| o**O**oo | a-**NAL**-y-sis, re-**LI**-a-ble, de-**PEN**-den-cy |
| **O**ooo | **IN**-fra-struc-ture, **CAT**-e-go-ry, **AC**-cu-ra-cy |
| Noun vs verb | **RE**-cord / re-**CORD** · **PRE**-sent / pre-**SENT** · **OB**-ject / ob-**JECT** · **IM**-port / im-**PORT** · **UP**-date / up-**DATE** |

Rule: words ending in **-tion, -sion, -ic, -ity** → stress the syllable **before**: *infor**MA**tion, sta**TIS**tic, scala**BIL**ity*.

## 4. Intonation
- ↘ Falling: statements and wh- questions — *Where's the file?↘*
- ↗ Rising: yes/no questions — *Is it ready?↗*
- Lists: rise, rise, fall — *Python↗, SQL↗ and Power BI↘.*

## 5. Shadowing method (best listening exercise)
1. Choose 1–2 minutes of audio with transcript (TED talk, YouTube tech talk, podcast).
2. Listen once without reading.
3. Listen with the transcript; underline linked sounds.
4. Play sentence by sentence and repeat **at the same time** as the speaker.
5. Record yourself and compare.

### Recommended listening (tech)
- Podcasts: *Data Engineering Podcast*, *Talk Python To Me*, *Software Engineering Daily*, *Practical AI*.
- YouTube: conference talks (PyCon, PyData, Data Council), StatQuest.
- Use **0.75× speed** at first, then 1×, then 1.25×.
