# 📉 Cálculo y Optimización para Ciencia de Datos

El cálculo no es solo resolver integrales; es el estudio del **cambio**. En el mundo bancario y de la IA, el cambio es la clave: ¿Cómo cambia la probabilidad de default si subimos la tasa de interés? ¿Cómo cambia el error del modelo si ajustamos un peso?

- [[CAL - Integrales]]: El área bajo la curva y su relación con la Probabilidad.

### 3. Optimización (La Búsqueda de la Eficiencia)
- [[CAL - Descenzo del Gradiente]]: El algoritmo fundamental para minimizar el error.

## 🏦 Aplicaciones en la Industria Bancaria
El cálculo es la herramienta para la toma de decisiones optimizadas:
- **Sensibilidad Financiera**: Calcular el "Delta" o la sensibilidad de un derivado financiero ante el cambio del precio del activo subyacente.
- **Ajuste de Modelos de Riesgo**: Minimizar la función de pérdida para que el modelo de scoring sea lo más preciso posible.
- **Optimización de Capital**: Encontrar la mezcla óptima de activos en una cartera para maximizar el retorno sujeto a regulaciones de Basilea III.
