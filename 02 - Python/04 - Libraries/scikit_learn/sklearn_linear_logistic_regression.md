## 1. Beginner Level: Ordinary Least Squares (OLS) Linear Regression

Linear regression fits a linear equation to minimize the residual sum of squares between observed targets and predictions generated by the linear approximation ($y = X\beta + \epsilon$).

```python
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error, r2_score

# Training data
X_train = np.array([[1], [2], [3], [4], [5]])
y_train = np.array([3, 5, 7, 9, 11]) # Exact linear relationship: y = 2x + 1

# Instantiate and fit
model = LinearRegression()
model.fit(X_train, y_train)

# Predictions and Evaluation Metrics
y_pred = model.predict(X_train)
print("MSE:", mean_squared_error(y_train, y_pred)) # Output: ~0.0
print("R2 Score:", r2_score(y_train, y_pred))       # Output: 1.0 (Perfect fit)
```
